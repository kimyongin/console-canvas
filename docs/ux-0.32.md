## 직접 사용

별도 localhost54240의 가상 NORTH 두 문서로 사용했다. 실제 사용자 프로필·문서에 테스트 편집을 하지 않았다.

- 버튼/검색 영역에 주석을 남겨 전달→넓게 보기/100%→하단 카드를 실제 휠로 읽었다. PNG는1440px 폭 그대로이고 세로 스크롤1440px에서 닫기의 hit가 실제 버튼이었다. 닫기를 클릭해 종료했다.
- 별도 구현 화면을 연결하고 요청2→100%→선택 요청 위치로 이동했다. 양쪽 프레임의 clientHeight308/scrollHeight1135, scrollTop393.5/scrollLeft237로 상세 검색 영역이 보였다. 이전의 프레임1137px 확장/scrollTop0과 구별한다.
- 추가 수정 판정/메모를 남기고 기록 이름을 ‘1차 · 검색 필드 정리’로 바꿨다. 영구 삭제의 별도 확인을 열고 취소했다. 실제 영구 삭제는 직접 사용으로 실행하지 않았다.
- 최신 번들로 문서를 다시 열어 이름·판정/메모를 확인했다. 유일한 기록을 휴지통 이동→복구한 뒤 선택값이 빈 상태임을 확인하고, 명시적으로 선택해 같은 메모 ‘필드 간격을16px로 맞춰 주세요.’를 읽었다.

증빙은 Git 제외 `local/ux-032/handoff-wide-100.png`, `review-100-focus.png`, `record-management.png`다. 자동 검증과 직접 사용을 구분한다.
