# MIT 적용과 실제 OS 검증 · 0.51.2

2026-11-01. 사용자가 MIT 적용을 승인했다. 이전 라이선스 보류 기록은 당시 기록으로 유지하며 현재 결정은 이 문서와 `LICENSE`를 따른다.

## MIT 배포

- 최상위 `LICENSE`: MIT 전문, `Copyright (c) 2026 kimyongin`. package/lockfile에도 MIT를 표기했다. 의존성 고지와 저작권은 변경하지 않았다.
- 공개 런타임 목록에 LICENSE를 포함해 앱·런타임 ZIP에 같은 원문을 넣는다. 스킬 ZIP의 최상위 LICENSE도 같은 파일에서 생성한다.
- 스킬 설치/자동 업데이트의 관리 파일에 LICENSE를 포함했다. 기존 관리 파일과 같은 백업·원자 교체·실패 롤백을 사용하며 개인 파일을 보존한다.
- 단독 HTML에는 화면에 표시하지 않는 JSON으로 프로젝트 라이선스와 제3자 고지 전문을 함께 넣는다. 배포 디렉터리에도 LICENSE를 복사한다.
- 초기 단독 HTML 검사에서 라이선스를 넣기 위한 두 번째 문자열 치환이 번들 안의 문자열을 변경하는 결함을 발견했다. 삽입을 한 번으로 합친 뒤 실제 standalone 부팅과 라이선스 전문 일치를 검증했다.
- Python 패키징 검사는 런타임/스킬 ZIP·단독 HTML의 프로젝트 라이선스 및 제3자 고지 원문 일치를 확인한다.

## 실제 설치 앱 사용

사용자 앱을 정상 종료하고 앱·프로필·개인 스킬을 백업했다. 0.51.2를 같은 고정 Apple Development 신원으로 서명/strict 검증·DMG 무결성 확인 후 설치했다. 앱을 두 개 실행하지 않고 별도 프로필/포트59120에서 아래를 직접 조작했다.

조작 도구의 초기 상태 조회 지연·AX setValue·선택 대상 오류와 재시도는 원시 로그에 보존했다. 성공한 후속 경로만으로 첫 실패를 지우거나 모든 native 체크를 일괄 통과로 쓰지 않았다. 실제 OS 권한 오류/저장 실패 경로는 아직 직접 검증하지 않았으며 자동 파일 실패/롤백 검사와 구분한다.

## 영상 실험

#73의 영상 차이를 줄이려고 촬영 직전에 원본 VIDEO를 읽어 분리된 canvas에 보관하고 나중 DOM 직렬화에서 사용하는 일반 실험을 했다. 원본 DOM·재생 상태는 변경하지 않았다. 실제 IKEA 결과는 초기89.732%·문서92.545%(RGB16)였다. 이전90.616/92.673%와 방문 시점도 다르므로 악화 원인을 확정하지 않지만,95% 달성이나 개선을 입증하지 못했다. **실험은 제품 코드에서 제거했다.** 실패 원본/복제/차이 PNG와 실험 코드는 ignored 로컬 증거에 남긴다.

다음 해법은 raw 영상과 Chromium 합성 사진의 시점 일치를 입증해야 한다. 원본 정지·페이지 전용 분기·오버레이를 영상에 굽기·전체 평탄화·비교 마스크로 조건을 우회하지 않는다.

## 검증·복귀

`npm run check`: Python49·Node42·전체 Chromium suite 및 standalone 부팅 통과. `npm run test:desktop:offscreen`: SDK16/최신6, 시각 입력8·범위5, 저장·목표·주석·작업 기록·스킬·정상 종료/재실행 통과.

시험 앱을 정상 종료하고 원래 사용자 프로필/포트8849로 복귀했다. 앱 본체는1개다. 기존 사용자 CC-5 전체 티켓 SHA-256은 전후 같고 주석·고정 목표·이미지3개가 유지됐다. 마지막 사용자 티켓 CC-6도 그대로 복원됐다. 소스와 설치 런타임·가이드·개인 스킬 및 새 LICENSE 바이트 일치, 설치 경로 MCP0.51.2를 확인했다. SDK를 앱 준비 전에 한 번 호출했을 때의 not_connected와 실제 연결 준비 뒤 성공을 구분한다.

## 남은 조건

- #7: 실제 OS 직접 검증 범위를 갱신했다. 실제 IME 조합·조합 중 Esc/Enter와 OS 권한/저장 실패 조건은 남는다.
- #73: 움직이는 영상의95% 미달은 미해결이다.
- #152: MIT 결정/배포 포함은 완료다. 이 Mac의 코드 서명 신원에는 Apple Development1개, Developer ID Application0개다. Developer ID 발급 자격·인증서·공증·외부 기기 설치를 확인하기 전 공개 배포 완료로 표시하지 않는다. 회원 가입·유료 결제·키체인 ACL 확대·인증서 폐기는 하지 않았다.

Apple의 [Developer ID 안내](https://developer.apple.com/help/account/certificates/create-developer-id-certificates)와 [공증 안내](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)를 기준으로 공개 배포와 현재 개발 기기 설치를 구분한다.

증거·백업은 ignored `local/license-0512/`에 있다. 실제 캡처·사용자 자료·프로필·인증 정보를 커밋하지 않는다.
