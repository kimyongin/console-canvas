## 최신 소스 · 0.19.2 · 검증 범위 분리

2026-10-25, 사용자 승인으로 [변경별 검증 기준](validation-policy.md)을 적용했다. 공통 웹 UI 완료, 영향받은 Electron 통합, 사용자 설치 앱 배포를 나눈다. 작업 지침·PRD·README·스킬 원본과 생성 가이드/스킬 ZIP을 같은 기준으로 갱신했다. MCP 도구·프로토콜·Electron 실행 코드는 변경하지 않았다.

- 새 기본 `npm run check` 종료 코드 0: TypeScript·포맷·번들/스킬 패키징, Python 39·Node 27·Chromium 321 통과. standalone 364요소·외부 스크립트 없음과 iframe 경계를 넘는 영역 선택도 확인했다.
- `--unknown`, `--web --all`, 중복 `--all`은 사용법 오류와 종료 코드 1로 거절했다. 기본/명시적 웹 검사는 앱 통합을 실행하지 않으며, `check:all`은 통합 실패를 숨기거나 offscreen으로 자동 전환하지 않는다.
- 스킬 제작 도구의 `quick_validate.py` 통과. 생성 `agent-guide.md`·스킬 ZIP의 SKILL.md와 원본, 런타임 체크섬을 대조했다.
- 이번 변경은 검사/지침 분리이며 UI 동작 변경은 없다. 이전 버전의 브라우저 직접 사용 증빙을 유지한다. Electron 통합·OS 직접 사용·앱 설치/재실행을 새로 수행한 것으로 보고하지 않는다.

소스/생성 웹·스킬은 0.19.2, 마지막 생성 앱 번들은 0.19.1, 사용자 설치 앱은 0.16.1이다. 사용자 앱·프로필·설치 스킬은 변경하지 않았다. 로컬 실행 로그는 Git 제외 경로 `local/validation-policy-check.log`에 있다. UI/구현 티켓 25개 완료와 별도 통합 [#7](https://github.com/kimyongin/console-canvas/issues/7)·배포 [#27](https://github.com/kimyongin/console-canvas/issues/27)의 남은 조건은 [추적표](ticket-review.md)를 따른다. 미검증 조건은 이관했으며 통과로 바꾸지 않았다.


설치 전 실제 앱을 메뉴로 정상 종료해 주석 초안·추가 설명을 flush한 뒤 기존 앱과 사용자 프로필을 백업했다. 0.14.0 앱/ZIP/DMG를 빌드해 DMG 체크섬을 검증하고 ~/Applications의 설치 앱을 갱신했다. 네이티브 UI로 실제 설치 앱을 다시 열어 한 줄 도구 모음·모드 버튼 제거·중앙 스냅샷 트리·기존 3개 버전·오른쪽 변경 이력을 확인했다. 원래 사용자 문서에는 테스트 편집을 적용하지 않았다.

설치된 앱의 공식 SDK 읽기 전용 조회는 버전 0.14.0·13개 도구·앱 지침·마지막 문서 364개 요소·3개 활성 스냅샷을 확인했다. 설치된 스킬의 관리 파일 4개가 앱 번들 ZIP과 바이트 단위로 일치한다. 전체 프로필의 7개 문서·13개 스냅샷에 대해 캡처, 제목/휴지통, 편집, 주석, 추가 설명, 전체 타임라인 지문이 설치 전후 동일하다. 설치 전은 정상 종료한 cold 백업이고, 설치 후는 UI 잠금 상태에서 DB 파일들이 복사 전후 바뀌지 않음을 확인한 사본이다. 실제 프로필을 감사용 Electron으로 직접 열지 않았다.

직접 사용은 별도 브라우저의 가상 NORTH에서 컴포넌트 선택→아이콘→모달 주석 작성→저장→이름 모달 스냅샷 저장을 수행했다. 설치 앱 재실행과 기존 스냅샷 드롭다운도 직접 확인했다. 이후 Mac이 잠겨 별도 네이티브 QA 프로필에서 추가 마우스 조작은 수행하지 못했다. 사용자는 현재 잠금 해제가 불가능하다고 답했다. 이 추가 수동 검증을 완료한 것으로 보고하지 않는다. 임시 Electron 프로필에서 동일 기능의 자동 테스트·MCP·정상 종료/재실행 검사는 완료했다.

Python 39개, Node 23개, 실제 Chromium 227개가 통과했다. Chromium 세부 결과는 integration 61 / snapshots 11 / panels 22 / storage 7 / ux 19 / selection 35 / trash 19 / placement 15 / evolution 21 / graphflow 18이다. 독립 HTML 실행과 실제 포인터의 iframe 경계 영역 선택도 통과했다.

추가 graphflow 검사는 탭 없는 오른쪽 이력, 속성 전후 값과 주석 본문 동시 표시, 이름 저장 직후 목록 열기, 선택 이름 표시, 비파괴 미리보기, 명시적 과거 적용, A→B→C와 A→D의 부모 ID·SVG 연결·다른 줄, 가로 스크롤, 미래 C와 병렬 D 재방문, 패널 접기/다시 열기, IndexedDB 재열기 뒤 버전 이동을 확인한다. 렌더링 이미지를 조사하던 중 기존 목록 CSS가 그래프 노드의 absolute 위치를 덮어쓰는 문제를 발견했다. 선택자를 한정해 수정했으며 같은 가지의 카드가 실제 화면에서 수평으로 정렬되는 검사를 추가했다.

Mac 잠금 상태에서 표준 `npm run check`의 데스크톱 단계는 `Current display surface not available for capture`로 중단된다. 표준 전체 명령이 통과한 것으로 기록하지 않는다. 별도 로컬 시험 래퍼에서는 원본 DOM 수집은 그대로 실행하고 스크린샷만 가상 NORTH 이미지로 대체했다. 이미지 렌더링용 Chromium 창은 offscreen 모드로 실행하고 마지막 네이티브 창 스크린샷은 제외했다. 이 조건에서 공식 MCP SDK 22개 검사, 격리 앱의 주석 초안·추가 설명·복사본·스냅샷·문서/버전 이름·휴지통·패널 너비 보존과 정상 종료/재실행 검사가 통과했다. PNG MCP 응답도 실제 이미지 블록으로 확인했다. 프로덕션 코드에 캡처 대체나 잠금 우회 경로를 추가하지 않았다.

따라서 총 311개 기능 검사와 별도 종료/재실행 검증은 위 조건에서 통과했다. 잠긴 설치 앱을 마우스로 직접 조작하거나 원본 화면의 실제 스크린샷 수집을 새로 검증한 것은 아니다. 사용자가 잠금 상태를 확인하고 가능한 검사 진행을 요청했다. 가상 데이터의 실제 Chromium 렌더링으로 그래프·하단 미리보기·통합 이력의 배치를 검토했으며, 이 이미지는 잠긴 사용자 화면 캡처가 아니다.

설치 앱은 0.15.0으로 교체 후 실행했다. 공식 SDK는 설치 번들의 MCP 버전 0.15.0·13개 도구·앱 번들 지침 제공을 확인했지만, 잠긴 실제 앱의 화면 목록이 비어 있어 설치 앱의 활성 화면 조회는 완료하지 못했다. 같은 설치 런타임을 사용자 프로필의 격리 사본으로 열면 마지막 문서의 364개 요소·3개 활성 스냅샷·탭 없는 변경 이력·명시적인 스냅샷 목록 버튼이 준비 상태로 로드된다. 이 사본 조회를 실제 설치 창의 직접 조작으로 보고하지 않는다.

설치된 스킬의 관리 파일 4개는 앱 번들 ZIP과 바이트 단위로 일치한다. 원래 사용자 프로필을 시험 도구로 직접 열지 않고 사본의 지문을 대조했다. 7개 문서·13개 전체 스냅샷의 캡처·이름/휴지통 메타데이터·편집·주석·추가 설명·전체 타임라인이 설치 전후 동일하다. 설치 전은 정상 종료한 cold 백업이며 설치 후는 IndexedDB 파일 21개의 복사 전후/사본 해시 일치를 확인한 사본이다.

로컬 증빙은 Git에서 제외한 `local/upgrade-0.15.0`의 `check.log`, `offscreen-check.log`, 시험 래퍼, `build.log`, `inventory-before.json`, `inventory-after.json`, `profile-copy-audit.json`, `installed-mcp-transport.json`, `installed-copy-reopen.json`, `graph-preview.png`에 있다. 네이티브 직접 조작·원본 화면 캡처·설치 앱 활성 화면 MCP 조회는 잠금 해제 후 남은 검증 항목이다.
