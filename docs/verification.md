# 0.10 영역 선택·복사/붙여넣기 검증

환경: macOS Apple Silicon, 공식 Electron 45.0.0, Python 3.9, Node.js 24, MCP SDK 1.32.2.

## 통합 명령

```sh
npm ci
npm run check
```

별도 설치한 Electron은 `ELECTRON_BINARY=/absolute/path/to/Electron npm run check`로 지정한다. 결과는 `dist/browser-checks.json`, `dist/desktop-checks.json`과 `local/mcp-native-verification.json`에 기록한다. 테스트는 가상 NORTH만 사용하며 임시 프로필·포트를 삭제한다.

## 검증 범위

- Python 38개: 전달 파일·스킬 설치·부모/자식 해석·MCP 스키마·HTTP 출처/인증/정적 파일 경계·앱 업데이트 적용과 롤백·스킬 자동 동기화.
- Node 18개: 작업 묶음 원자성·수동/MCP 이동 한계 일치·저장 왕복 좌표·계층 인덱스·저장 합치기/문서 간 보존/실패·저장 응답과 종료·업데이트 전 flush·mainFrame/URL 경계.
- Chromium 147개: 수집·편집·내보내기 61개, 스냅샷/파일 왕복 11개, 패널 접기/드래그/키보드/너비 복원 23개, 저장소/목록/문서 전환 7개, 편집 UX 19개, 영역 선택·복사/붙여넣기 26개. 358개 표시 요소의 이동·삭제·복원을 포함한다.
- 독립 HTML: file URL에서 샘플 실행·300개 이상 요소·외부 스크립트 없는 JS 번들·CSS import 없는 스타일 번들을 확인한다.
- 공식 SDK 18개: 실제 stdio MCP의 11개 도구 발견·앱 지침 조회·요소 조회·이동/삭제/주석·실행 취소/복원·재전송·버전 충돌·스냅샷 이동과 자동 복구.
- 실제 Electron 앱: 별도 홈·프로필·포트에서 원본 NORTH를 가져오고 원본 DOM 무변경, 원본의 preload 미노출, 세 뷰의 sandbox/contextIsolation/Node 비활성화를 확인한다. 일반 창 닫기로 flush한 뒤 앱을 다시 실행해 마지막 문서·이동·주석 초안·추가 설명·스냅샷·패널 너비·편집기 주소창 숨김을 확인한다.

이 검증은 실제 사용자 사이트나 개인 Chrome 확장의 설치/권한 경계를 다루지 않는다. GitHub의 새 릴리스를 다운로드해 설치 앱을 교체하는 전체 업데이트는 이번 리팩토링 검증에서 실행하지 않는다. 업데이트 전 공통 flush와 적용·롤백은 각각 Node/Python 검사로 확인한다. 개발용 ad-hoc 서명과 macOS 공증 여부는 이 리팩토링의 변경 범위 밖이다.

0.9 UX 검사는 문서 정보 접기, 읽기 쉬운 요소와 경로, 일반/Alt 선택, 그룹 이동·삭제·정렬·실행 취소·드래그 취소·하위 중복 방지, 팝오버 주석 자동 저장과 검색, 스냅샷 이미지, 두 저장 버전의 비파괴 비교, 전달 기준 버전, 파일 왕복을 확인한다. 네이티브 파일 저장은 취소 시 무변경·원자적 저장·경로 주입 거부를 별도 검사한다.

0.10 검사는 영역 미리보기·완전 포함·부모/자식 중복 제외·추가 선택·Esc 취소·MCP 쓰기 잠금, 복제본과 하위 요소·주석의 이동·실행 취소·스냅샷·파일 및 IndexedDB 재열기를 확인한다. 실제 포인터 입력으로 iframe 경계를 넘는 영역 선택을 검증하고, 별도 Electron 프로필에서 복사본을 저장한 뒤 정상 종료·재실행 시 DOM·주석 복원을 확인한다. 복사 데이터는 원본 캡처 노드만 참조하며 임의 HTML·외부 노드·중복 ID·잘못된 계층과 비정상 좌표를 거부한다.

0.10.1 사용성 보정: 선택한 컨테이너의 문구에서 묶음 드래그, Alt 세부 선택, Cmd+컨테이너 클릭, 다중 선택의 정렬·삭제 범위 및 전체 크기 표시, 삭제된 복사본과 해당 주석의 전달 구분을 회귀 검사한다.
