# v0.4.0 검증 범위

환경: macOS Apple Silicon, 공식 Electron 45.0.0, Python 3.9, 공식 MCP JavaScript SDK 1.32.2.

## 통과한 검사

- Python 검사 21개: 기존 전달 파일 해석, 스킬 설치, MCP 스키마, 연결 화면 범위, 명령 재전송, 허용 출처, 토큰 인증, Host 검사, 파일 경로 제한, 스냅샷 쓰기 스키마, 이전 브리지 종료 응답 누락·앱 업데이트 회귀.
- 브라우저 통합 검사 61개: 358개 표시 요소 이동·삭제·복원, 요소 주석·배지, 전후 내보내기, 원자적 MCP 편집, 버전 충돌, 사용자 편집 중 거절, 실행 취소·복원, 스냅샷 과거·미래 이동, 분기, 미저장 작업 자동 보관, 목록 페이지 조회.
- 공식 SDK 실제 연결 검사 17개: stdio 도구 발견, 독립 앱의 캡처 화면 조회, 요소 위치 변경, 아이콘 삭제, 주석 생성·수정·삭제, 작업 묶음 취소·복원, 중복 요청 방지, 오래된 버전 거절, 잘못된 작업 묶음의 무변경, 스냅샷 저장·복원·재전송·자동 작업 복구·복원 취소.
- 스냅샷 UI·저장 검사 11개: 이름 있는 버전 저장, 목록·이전·다음 이동, 주석·추가 설명 복원, IndexedDB 문서 재실행, 파일 내보내기·재가져오기, 복원 작업의 실행 취소·다시 실행.
- 설치한 macOS 앱에서 직접 가져온 NORTH 샘플 콘솔을 대상으로 검증했으며, 설치한 스킬의 MCP 실행 경로로도 같은 SDK 검사를 통과했다.
- 설치 앱의 런타임 파일과 배포 런타임 ZIP의 일치를 확인했다. 로컬 연결 파일은 0600 권한으로 생성된다.

## 재현

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 -m http.server 8848 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8848/tests/integration.html`과 `http://127.0.0.1:8848/tests/snapshots.html`을 연다. 이어서 독립 앱에서 **샘플 콘솔 → 이 화면 가져오기**로 새 복제본을 연다.

```sh
npm ci
node scripts/verify_mcp.mjs
```

SDK 스크립트는 로컬 `fixtures/console.html`을 가져온 편집기만 선택한다. 실제 사용자 화면에 임의 테스트 변경을 적용하지 않는다. 최종 시안은 가상 샘플 편집기에 남는다.

## 남은 범위

배포 앱은 개발용 ad-hoc 서명을 사용하며 macOS 배포 공증을 받지 않았다. 현재 앱 배포는 macOS Apple Silicon용이다. Python 3.9 이상이 필요하다. 실제 서비스의 SSO·기업 프록시·다중 도메인 인증은 사이트별 검증이 필요하다. 기존 Chrome 확장 설치·탭 권한 경계는 별도 실사용 검증 전이다. iframe/Canvas/영상 내부 자동 분해 등 기존 캡처 범위 제한은 유지된다.
