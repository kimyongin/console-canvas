집중 보기는 기존 패널 너비/접힘 환경설정을 덮어쓰지 않고 복귀한다. 주석·스냅샷·분기·휴지통·원본 식별자를 삭제하는 이전 작업은 없다. 보관+복사를 AI 실행 성공으로 표시하지 않는다. 복제본만 편집하며 원본 DOM/업무 이벤트는 그대로다.

## 횟수와 직접 사용

링크·메뉴/하위 메뉴·초점·입력·스크롤·확정·닫기·복귀·옵션·OS/외부 전달을 모두 센다. 아래는 동일 시작 조건의 **부분합**이다. 미측정 진입·탐색 N/N′는 0이 아니며 전체 절감률을 만들지 않는다. 단축키 1회는 이미 알고 사용하는 경우이며 메뉴에서 발견하는 비용은 별도다.

| 흐름 | 기준 → 기본 구현 | 선택 경로 |
| --- | --- | --- |
| U01 가져오기부터 전달 | 21+N → 20+N′ | 이미지 복사 키 사용 시 19+N′ |
| U02 기존 화면 편집·전달 | 13+N 유지 | 이미지 복사 키 사용 시 12+N′ |
| U03 새 대상 10개 주석·전달 | 46+N 유지 | 개별 다중 선택 대기열 37+N′, 정확한 영역 선택 가능 시 28+N′ |
| U04 기존 주석 10개 수정·전달 | 27+N 유지 | 이미지 복사 키 사용 시 26+N′ |
| U05 결과 재수집·10개 판정·메모 2개·PNG | 44+N → 28+N′ | 다음 이동 켜기 1회 포함 20+N′ |
| U06 MCP 요청 전달·후보 적용 | 13+N → 11+N′ | 외부 대화 4회 포함, 생성 대기는 별도 |
| U07 C에서 A로 가서 D 분기 | 8+N 유지 | 미리보기·명시적 이동·이름 입력 유지 |

전달 전 새 주석 10개: 개별 선택10+열기1+입력10+다음9+완료1=31회. 정확한 영역 선택1이면22회. 판정10개: 첫 판정1+다음 선택9+판정9=19회, 옵션 선택1+판정10=11회. 대상 선택·옵션 켜기를 생략한10회로 보고하지 않는다.

별도 localhost의 가상 NORTH에서 직접 사용했다. 고객 등록·내보내기 수정키+클릭 선택→주석 열기→첫 입력→다음→둘째 입력→완료 **7회**(선택2+열기1+입력2+다음1+완료1)를 확인했다. 대상이 보이는 최근 문서 전환은 메뉴→문서 **2회**. 기본 판정 제자리·직전 판정 취소·옵션 켜기 후 다음 요청 이동·새로고침 후 주석/판정 복원을 확인했다. 사진 없는 샘플의 비교 비활성 이유도 확인했다. 탐색 N·외부 전달·실제 프로젝트 완료 시간은 실측하지 않았다.

## 검증과 한계

- `npm run check` 종료 코드0: 타입·포맷·번들/스킬·Python45·Node49·Chromium581+smoke2. 새 `action-ux`35개와 `shell-actions`14개는 보존 요약/관리 동선/고정 주석/복구 누적/실제 IndexedDB 오류·판정 롤백/결과 고정/영역 조절/자동 다운로드 동의를 검증한다. 기본 검사에 사용자 설치 앱은 포함되지 않는다.
- `npm run test:desktop`: 격리 프로필·포트·가상 NORTH의 실제 Electron IPC/수집. 검토 목표 보존·결과 연결·취소·주소 초점, 원본 무변경, 정상 종료/재실행·주석/전체 스냅샷/휴지통/패널 복원 통과. 범위 수집/지연 범위 거절5개, 공식 SDK25개+현대 SDK17개(2026-07-28) 통과. 설치 앱 직접 사용은 아니다.
- skill-creator `quick_validate.py` 통과. 가이드/스킬/런타임은 같은 소스에서 생성. MCP 도구19개와 쓰기 revision/operation_id 유지, 수집 상태 판독 필드만 추가.
- 저장 실패 검사에서 큐 대기 완료를 DB 성공으로 오인하는 결함을 발견해 실제 `flushEditor()` 결과를 기다리도록 수정했다. 실패 시 판정/메모를 마지막 저장 상태로 되돌리고 다음 항목으로 넘어가지 않는다.
- 여러 사람의 초보/숙련자 비교, 실제 IME·스크린리더·모든 OS/외부 전달·유료 AI 추론은 수행하지 않았다. 액션 감소만으로 시간/오류율 개선을 단정하지 않는다. 설치 배포는 [검증 기준](validation-policy.md)에 따라 별도다.

로그·가상 화면은 Git 제외 경로 `local/action-ux-027/`에 보관한다. 사용자 문서에 테스트 편집을 하지 않았다.
