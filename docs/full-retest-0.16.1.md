# 0.16.1 전체 기능 재검사

2026-10-25. 사용자 요청에 따라 기존 결과를 재사용하지 않고 전체 자동 검사를 다시 실행하고, 설치 런타임의 별도 브라우저 QA 문서에서 직접 조작을 추가했다. 실제 사용자 문서·앱 설치·스킬 파일은 변경하지 않았다. 제품 코드 수정은 없다.

## 직접 사용과 발견 사항

설치된 0.16.1을 제공하는 루프백 URL을 CUA 인앱 브라우저로 열고 **QA 전체 기능 재검사**라는 새 가상 NORTH 문서만 편집했다. Mac 잠금 상태에서 브라우저 클릭·키 입력은 가능하지만 Electron 창 사용이나 실제 macOS IME 조합으로 간주하지 않는다.

새 문서에서 요소 위치/주석/삭제된 복사본을 포함한 A/B/C를 저장하고 A에서 새 D를 만들었다. B의 부모와 D의 부모가 모두 A이고 C의 부모는 B였다. A/B/C의 그래프 Y좌표는 303.375px, D는 417.375px였다. C 재적용 후 D로 돌아가도 5개 버전이 모두 남았다. 좌표 주석의 작성·재편집·삭제·실행 취소도 확인했다. PNG를 실제 클립보드에서 꺼내 열어 요소/삭제/위치 주석의 3개 번호와 카드, 추가 설명을 확인했다.

직전 점검에서 기록한 4개 개선점은 아직 수정하지 않았다. 전달 모달의 낮은 창에서의 버튼 노출, 스냅샷 이름 변경 후 그래프 복귀, 긴 PNG 제목 압축, 삭제 복사본 참고 이미지 잘림이다. 이번 PNG에서도 삭제 복사본 참고 영역 잘림이 보였다. 자세한 재현은 [사용 기록](usability-check.md)에 있다.

## 남은 조건과 증빙

- 네이티브 표시 화면 새 캡처·일반 사용자 창/메뉴 직접 조작·실제 macOS IME·Chrome 확장 권한 경계는 이번 환경에서 완료하지 못했다. 새 자동 업데이트 클릭→교체는 이번에 반복하지 않았다. 관련 티켓은 닫지 않는다.
- 사용자 자료에는 테스트 편집을 적용하지 않았다. 모든 자동 검사는 별도 임시 프로필/포트, 직접 조작은 별도 브라우저 저장소의 가상 문서를 사용했다.
- 원시 로그: Git 제외 `local/full-retest-0.16.1.log`, `local/installed-full-retest-0.16.1.log`, `local/installed-desktop-retest-0.16.1.log`.
- 직접 사용 증빙: Git 제외 `local/retest-branches.png`, `local/retest-review.png`, `local/retest-export.png`. 과거 결과와 이번 결과를 혼합해 통과 수를 늘리지 않는다.
