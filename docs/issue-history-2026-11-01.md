## 작업

- PRD AC-01~AC-18별로 담당 기능 티켓·정상/오류 시나리오·명령/환경·증빙·미검증을 연결한 검증 표를 남긴다. 전수 대조표의 112개 정적 조작 정의·동적 메뉴·단축키·네이티브 메뉴·CLI·13개 MCP도 누락/유령 기능 없이 대조한다.
- npm run check·타입 검사·생성물/체크섬 검사를 수행하고 정상 사용자 동작을 검증한다. 구현을 그대로 복제한 검사로 완료 처리하지 않는다.
- #8 PNG 저장의 실제 IPC/파일·취소/실패, #9 잘못된 파일의 UI/DB 무변경, #10 quota 중 긴급 백업/재열기, #11 복원 저장 실패의 보호/롤백을 최종 앱에서 재검증한다.
- 공식 SDK에서 13개 도구와 UI↔MCP 상태, revision conflict/busy/operation_id 재시도/잘못된 묶음의 비부분 적용·undo, persisted/save_error·active/preview 의미를 확인한다. 토큰·로그인·사용자 캡처를 커밋하지 않는다.
- 원본 읽기 전용/이벤트 비실행, 복제본 정제, sandbox/contextIsolation/webSecurity, 신뢰 프레임 IPC를 유지한다. 보안 경계를 TS 타입이나 UI 숨김으로 대신하지 않는다.
- 두 버전 비교(AC-15), 레이어/부모 선택·정렬/간격/스냅/nudge/배율과 세션 undo 수명(AC-16), 파일 검증/긴급 백업(AC-17), 복원 실패(AC-18)를 명시적으로 검사한다.
- standalone/확장 번들과 helper prepare/review/mcp의 체크섬·도움말·경로를 검증한다. CLI ZIP 지원과 에디터 JSON만 지원을 구별한다. 실제 Chrome 설치/탭 권한과 가상 브라우저 fixture 결과는 따로 기록한다.
- 기존/긴 이력·많은 버전에서 드래그·선택·검색·그래프 탐색을 전환 전 기준과 비교하고 장면 재생성/이벤트·구독 누수를 확인한다. 키보드·포커스·IME와 긴 이름/좁은 창도 실제 사용한다.

## 후속 검증 상태 · 0.38.3 / 2026-10-31

실제 모델의 -webkit-text-fill-color가 후보 등록 검증에서 거절되던 문제를 재현·수정했다. 안전한 vendor CSS는 허용하고 -moz-binding/behavior·실행/외부 URL CSS 차단은 유지한다. 이미 소비한 사용량/모델은 로컬 등록 실패에도 남기고 중복 추론하지 않는다. 실제 가상 NORTH 응답의 HTTP200/response.completed·후보1개와 수정 전 거절→수정 후 통과는 별도 진단으로 확인했다.

설치본0.38.3·암호화 로그인 보존·스킬/MCP 갱신과 기존7문서 전체 지문 보존을 확인했다. 고정 자체 서명으로도 Safe Storage가 다시 묻는 원인은 #153이다. 시작 시 계정 초기화를 지연해 일반 편집/MCP는 새 승인 없이 실행된다. 이 상태를 실제 ChatGPT 사용의 무재승인으로 보지 않는다.

**설치 UI의 실제3후보 생성·비교·명시 선택 적용·그 결과 재실행은 아직 미검증이다.** Native UI 도구는 시안 창 클릭 뒤 이전 AX/화면을 반환하고 좌표 클릭은 noWindowsAvailable이었다. MCP의 busy:true와 달라 통과 증거로 쓰지 않는다. 계정 로그인/모델/수정 소스의 실제 단일 추론, 제어환경3후보와 이 완주 조건을 구별한다. 공개 배포 적격·라이선스 조건도 그대로 남긴다.

전체 check:all Python60·Node81·Chromium923+smoke2·SDK25+modern17·nativeScopes5·실제 OS 암호화·정상 재실행 통과. docs/deployment-0.37.md의 최신 절을 따른다.
