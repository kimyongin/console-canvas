# 0.17.0 UX 개선

2026-10-25. 제안한 6개 개선을 티켓으로 만들고 구현했다. **소스·새 배포 빌드·가상 문서의 직접 사용 검증은 완료했고, 사용자 설치 앱 교체/재실행은 남아 있다.** Mac 잠금으로 기존 앱을 정상 종료할 수 없어 설치 앱·설치 스킬은 0.16.1을 유지했다. 실제 사용자 문서에는 테스트 편집을 하지 않았다.

## 데이터와 에이전트

- 별칭은 선택적인 세션 `layerNames`이며 원본 캡처에서 분리한다. 별칭이 없는 기존 문서에는 빈 필드를 추가하지 않는다. 버전 이동·캔버스 undo와 독립적인 문서 탐색 메타데이터다. 원본 ID·selector·문구는 바꾸지 않는다.
- MCP `list_elements`는 별칭 검색과 선택적인 `alias` 응답 필드를 제공한다. 기존 `name`·locator·명령·revision/operation_id 계약은 유지한다. 도구는 계속 13개다.
- 비모달 창을 열기만 했다고 MCP 편집을 차단하지 않는다. 실제 입력란에 포커스가 있거나 모달/드래그/미저장 주석 편집 중이면 기존 busy 보호를 적용한다.
- 스킬 원문·번들 가이드·확장 런타임 ZIP·앱용 스킬 ZIP을 빌드에서 갱신했다. 설치 스킬 자동 동기화는 사용자 앱 갱신과 함께 남아 있다.

## 검증 결과

- 타입·포맷·빌드, Python **39개**, Node **25개**, 실제 Chromium **286개** 통과. 기존 262개에 새 usability 24개를 더했다. 묶음 경계 단위 검사도 추가했다.
- 최종 앱 번들을 지정해 Chromium **286개**를 다시 통과했다. 소스/번들의 중복 실행을 서로 다른 기능 수로 세지 않는다.
- 최종 앱의 공식 MCP SDK **22개**, 실제 네이티브 PNG 파일 쓰기, 격리 스킬 설치/ZIP·정상 종료/재실행·문서명/주석/스냅샷/문서·버전 휴지통/패널 복원이 통과했다. Mac 잠금 때문에 원본 스크린샷만 명시적 가상 화면으로 대체한 offscreen 조건이다.
- 표준 `npm run check`는 표시 표면 캡처의 `Current display surface not available for capture`로 실패한다. 위 offscreen 성공을 표준 전체 성공으로 바꾸지 않는다.
- CUA 브라우저에서는 별도 가상 문서로 비모달 연속 편집·도구창 드래그·별칭/번호 주석 수정·전달 복귀·실제 PNG 복사·그래프 경계 드래그/키보드·문서 재열기를 직접 사용했다. 일반 사용자 Electron 창과 macOS IME 검증으로 간주하지 않는다.

직접 사용에서 발견한 그래프 경계 키의 캔버스 이동 충돌은 수정하고 편집/undo 무변경 검사를 추가했다. 숨겨진 앱 뷰에서도 PNG 출력이 미리보기 디코딩을 기다리지 않게 이미지 크기를 미리 예약해, 스크롤 복귀와 네이티브 파일 출력을 함께 검증했다. 테스트 서버도 종료 때 임시 연결을 닫는다.

## 배포와 남은 단계

0.17.0 앱·ZIP·DMG를 공식 Electron SHA-256 확인 후 생성하고 서명/DMG 무결성을 확인했다. 사용자 앱의 강제 종료나 프로필 조작은 하지 않았다. [AGENTS.md](../AGENTS.md)의 정상 저장·종료/백업·설치 갱신·재실행 기준에 따라 티켓의 설치 항목은 미완료로 남긴다. 잠금 해제 후 사용자 앱의 저장 완료·정상 종료·백업·설치·자료 보존/화면·설치 스킬 자동 갱신 확인이 필요하다.

원시 증빙은 Git 제외 `local/ux-0.17-final-check.log`, `local/ux-0.17-packaged-browser.log`, `local/ux-0.17-sdk.log`, `local/ux-0.17-desktop-build.log` 및 `local/ux-0.17-editor.png`, `local/ux-0.17-handoff.png`, `local/ux-0.17-graph.png`, `local/ux-0.17-review.png`에 있다. 실제 사용자 프로필·연결 토큰은 저장소에 넣지 않는다.
