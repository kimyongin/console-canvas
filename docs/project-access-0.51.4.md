# 연결된 앱의 전체 티켓 조회 · 0.51.4

2026-11-01 · [#187](https://github.com/kimyongin/console-canvas/issues/187). 사용자가 프로젝트별 에이전트 공개 옵션 제거를 요청했다. 현재 페이지를 여러 티켓으로 나누는 동작 변경은 사용자 재검토로 [#188](https://github.com/kimyongin/console-canvas/issues/188)에 보류한다. 새 티켓 생성/복제 동작은 변경하지 않았다.

## 변경

- 티켓 목록의 공개 체크박스와 상태/이벤트 처리, DB의 setProjectAccess/sharedProjects API, 티켓 조회/생성의 허용 프로젝트 필터를 제거했다. 체크박스를 숨겨 두거나 전체 공개 값을 강제로 저장하는 방식이 아니다.
- 인증해 연결한 작업 공간의 모든 저장 티켓을 ID/이름·목록·편집·주석·이미지·resource/구독에서 조회한다. project_id는 선택적 결과/대상 필터다. 새 프로젝트에 티켓을 생성해도 별도 공개 절차가 없다.
- 존재하지 않는 프로젝트 필터는 빈 목록/없는 티켓이다. 동명 티켓은 후보 ID를 반환하고 프로젝트로 좁힐 수 있다. UI 필터 변경은 MCP 조회 범위를 바꾸지 않는다.
- 빈 작업 공간도 resource를 제공한다. project_ids는 저장 목록에서 계산한 프로젝트 이름이며 권한 목록이 아니다. 브로커는 프로젝트 필터로 다른 작업 공간을 암묵 선택/병합하지 않는다.
- 연결 인증·루프백/원본 격리·휴지통 제외/복구·CAS/operation_id·사람의 목표 선택/구현 지시/검토 승인 조건은 유지한다.
- DB 버전을 변경하거나 사용자 자료를 이전/초기화하지 않는다. 과거 access:* 설정은 읽지 않는다. 캡처·편집·주석·목표·작업 기록과 개인 스킬 파일을 보존한다.

PRD CC-FR-05/CC-AC-18, MCP 도구 설명/서버 안내, README·구조·MCP/스킬 계약과 앱 제공 agent-guide를 같은 기준으로 갱신했다.

## 검증

- npm run check: Python52·Node43·전체 Chromium/standalone 통과. tickets51개는 과거 allowed:false 설정 무효화, 다른 프로젝트 ID 조회, 전체/프로젝트 필터, 페이지 구분, 프로젝트 간 동명, 휴지통/복구와 기존 편집/목표 계약을 검사한다.
- Python 브로커는 프로젝트 목록이 비어 있어도 연결 작업 공간에 새 프로젝트 필터를 전달하고, 다중 작업 공간을 프로젝트 필터로 암묵 선택하지 않는지 검사한다. 빈 workspace resource와 연결 종료도 확인했다.
- npm run test:desktop:offscreen: 공식 SDK17·최신 SDK6·시각8·범위/영상6·저장/정상 종료·재실행 통과. SDK에서 새 프로젝트 티켓 생성→목록/상세 조회를 별도 공개 없이 확인했다.
- 별도 브라우저 origin59141의 가상 샘플에서 실제 작업 티켓 목록을 열고 공개 옵션 제거와 모든 프로젝트 필터 선택을 확인했다. 사용자 프로필과 분리했으며 실제 OS IME 검사로 확대하지 않는다.
- 스킬 공식 quick_validate 통과. 공식 Electron SHA-256·같은 고정 Apple Development strict 서명·DMG 무결성 확인 후0.51.4 설치.

## 설치 앱의 CC-23 조회·자료 보존

현재 앱을 메뉴에서 정상 종료해 저장 응답을 기다린 뒤 앱·전체 사용자 프로필·개인 스킬을 백업했다. 설치본을 교체하고 원래 프로필8849의 CC-23으로 복귀했다. 설치 앱의 공식 MCP SDK로 CC-23 목록·상세·주석1개·이미지4개(현재 맥락과 확정 목표)를 실제 조회했다. 사용자 티켓에 테스트 쓰기/새 티켓 생성은 하지 않았다. 실행 당시 휴지통을 제외한 목록은 CC-23·CC-24의2개였다.

정상 종료 백업과 설치 후 프로필의 별도 복사본에서만 IndexedDB를 읽어 비교했다. captures/sessions/tickets/documents 각24개, settings3개, operations21개의 추가·삭제·내용 변경은 없었다. 세션 writer_id/storage_revision·저장 시각과 티켓/문서 갱신 시각은 비교에서 제외했다. 티켓 ID·편집 revision·편집/주석·undo/redo·고정 목표·상태/기록은 비교에 포함했다. 복사본 검사로 실제 사용자 DB를 수정하지 않았다.

소스와 설치 앱의 DB/티켓 workspace·모델·편집 번들·MCP·도구 계약·manifest·package 바이트가 같다. 앱 agent-guide와 자동 갱신된 개인 스킬·런타임 ZIP도 원문이 일치한다. 앱 본체는1개다. 원시 사용자 자료와 시험 로그/백업은 ignored local/project-access-0514에만 보관한다.
