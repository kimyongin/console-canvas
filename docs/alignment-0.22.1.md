# 0.22.1 · 화면 기준선·컨트롤 정렬

사용자가 0.22 편집기와 주석 캡처에서 지적한 정렬 불일치를 #59 / FR-02 / AC-58로 정리했다. 공통 웹 UI 변경이며 저장 형식·MCP 계약·캡처한 원본 HTML/CSS는 변경하지 않는다.

## 점검과 개선

| 화면 | 발견한 불일치 | 변경 |
| --- | --- | --- |
| 편집기 | 패널 헤더 44px와 중앙 59px, 하단 높이/경계선 차이 | 세 영역과 접힌 바의 헤더 48px·하단 44px, 같은 안쪽 여백. 이력 본문만 스크롤 |
| 주석 | 진행 문구가 선택 아래에만 붙어 이전/다음 중심이 어긋남, 제안 버튼의 끝선 불일치 | 32px 탐색 행과 별도 진행 행, 같은 폭 3열 제안/같은 행 높이, 좁은 창 한 열 |
| 주석 작은 창 | 완료/저장 상태가 아래로 잘림, 오버레이 스크롤바가 오른쪽 필드를 가림 | 본문 스크롤·독립 고정 footer, 바깥 여백에 스크롤바 공간, 대상 미리보기 100px |
| 속성 | 좌표 label과 input에 이중 테두리, 크기 차이 | 한 겹의 40px 필드와 22px 내부 입력, 정렬/방향 버튼 32px |
| 스냅샷 저장 | 폼만 16px 추가 들여쓰기, 저장과 취소가 다른 줄·다른 폭 | 이름 필드는 전체 너비, 취소/저장은 같은 줄·88px 최소 폭 |
| 스냅샷 목록 | 탐색 입력/버튼 크기 차이 | 검색/현재 버전·비교/이동 컨트롤 32px |
| 전달 | 라벨 글자 길이에 의존하는 필드 시작점 | 고정 64px 라벨 열, 동일한 선택 필드 시작점·너비, 출력 버튼 32px |
| AI 시안 | 비교 헤더/확대 선택·생성 액션의 제각각 높이 | 비교 헤더 48px·선택/액션 32px, 다중 행 후보는 콘텐츠 높이 유지 |
| 버전/구현 비교 | 선택·다음/이전·새 검토와 라벨 행 높이 차이 | 필드/액션 32px, 구현 검토 라벨 행 18px |
| 목록/연결/이름 변경 | 공통 버튼과 필드의 기본 높이 차이 | 공통 기본 버튼 32px. 아이콘/목록/긴 콘텐츠의 기존 예외 유지 |

`ui/styles/alignment.css`에서 정렬 토큰과 화면별 대응을 관리한다. 캡처 iframe 안에는 적용하지 않는다. 제안 버튼의 짧은 이름은 바꾸지만 실제 요청 문장은 그대로이며, 기존 주석과 반응형 문장의 교체 규칙을 유지한다. 주석 footer 이동은 DOM 배치 변경이며 기존 ID·저장·IME·취소/완료 계약을 유지한다.

## 직접 확인

가상 NORTH 문서에서 편집기·주석·속성·스냅샷 저장/그래프·전달·AI 시안·버전 비교·구현 비교를 직접 열고 치수를 측정했다. 1280×720에서 세 헤더는 y=72~120, 세 하단은 y=676~720으로 일치했다. 주석 이전/선택/다음, 전달 선택 필드/출력 버튼, 스냅샷 검색/이동, 두 비교 화면의 같은 행 컨트롤은 각각 32px로 정렬됐다. AI 비교 두 헤더는 같은 y와 48px 높이를 공유한다.

720×600·390×600 테스트 창에서도 주석 본문 스크롤과 고정 완료/저장 영역을 확인했다. 치수 점검은 공개 DOM의 사각형과 computed style만 사용했으며, 원본 사이트나 사용자 작업을 수정하지 않았다. 실제 테스트 캡처는 Git에서 제외한 `local/alignment-0.22.1/`에 있다.

`npm run check` 종료 코드 0: 타입·포맷·번들, Python 43·Node 33·Chromium 400과 smoke 2를 통과했다. 공개 런타임 111개 해시, 원본 가이드/스킬 ZIP과 배포 ZIP 자산의 일치도 확인했다. 공통 버튼/주석 DOM 변경 뒤 기존 주석·스냅샷·AI 시안·구현 검토의 저장/파일 왕복 회귀를 통과했다. 패널 버튼 검사는 실제 헤더 사각형 안에 포함되는지 확인해 고정 44px 값에 의존하지 않게 했다.

실행 로그는 `local/alignment-0.22.1-check.log`, 최종 캡처는 `local/alignment-0.22.1/01-editor.png`와 `02-comments.png`, 나머지 검토 화면은 같은 폴더의 03~14 이미지에 있다. [버전별 검증 기록](verification.md). 사용자 설치 앱 배포는 #27에서 별도로 추적한다.
