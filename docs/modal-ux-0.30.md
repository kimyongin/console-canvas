# 모달 중첩 최소화와 작업 복귀 · 0.30.0

2026-10-30 · 상위 [#113](https://github.com/kimyongin/console-canvas/issues/113). 사용자 승인 기준과 0.29.0의 대화창14개 정의·관련 경로 검토에서 발견한5건을 구현했다. 공통 UI 웹 검증으로 완료하며 사용자 설치 배포는 별도다.

## 설계 기준과 구현

큰 작업 모달은 하나를 기본으로 한다. 같은 작업의 검색·선택·설정은 본문 전환, 간단한 이름 변경은 인라인 편집이다. 작은 메뉴/드롭다운은 유지한다. 필요한 짧은 확인만 화면을 넓게 쓰는 작업 창 위에 허용한다. 이번 개선에는 새 확인 모달을 추가하지 않았다.

PRD의 제품 원칙7·FR-35·AC-106~110과 연결했다. 저장 형식·원본 locator·편집 오프셋·주석/스냅샷/휴지통·MCP19개 도구와 쓰기 계약은 바꾸지 않았다. 네이티브 수집/파일/클립보드·연결 인증 경계도 유지한다.

`ui/capture-workspace.js`가 정보/비교/복구의 본문·제목·뒤로·이탈 정리를 관리한다. 원본 비교/복구는 이제 별도 native dialog가 아닌 같은 dialog 안의 section이다. AI 연결은 본문을 숨겨 React의 요청/후보/입력 상태를 유지하고 기존 연결 폼을 이동했다가 반환한다. 숨긴 미리보기의 크기0 재측정을 피하며 같은 비교 배율을 보존한다. 결과 선택도 비교 DOM을 유지하고 본문을 전환한다.

## 직접 사용

별도 localhost `54231`과 가상 NORTH만 사용했다. 실제 사용자 문서·설치 앱·설치 스킬에는 테스트 편집을 하지 않았다.

- 이름 입력을 목록 안에서 열어 별도 이름 모달이 없는 상태를 확인하고 `0.30 목표 시안`으로 저장했다.
- AI 요청을 보관→연결 설정→실제 Escape로 같은 요청/연결 버튼에 복귀했다. 외부 에이전트에 요청을 보내거나 유료 API를 호출하지 않았다.
- 두 가상 캡처의 구현 결과 목록→검색→Escape→재진입에서 검색어 보존·모달1개/큰 팝오버0개를 확인했다. 결과 선택 후 같은 검토의 목표/구현 이름과 트리거 초점이 맞았다.
- 720×600 결과 본문의 x27.4~692.6, 하단564px, 문서 가로 넘침 없음·모달1/팝오버0을 확인하고 뷰포트를 복원했다.
- 샘플 가져오기 정보의 단일 넓은 작업 창을 확인했다. 이 샘플에는 실제 원본 사진이 없으므로 사진 비교/복구의 내부 동작은 가상 사진·mock 자산 응답의 Chromium 회귀로 검증했다. 실제 사이트 자산 다운로드/OS 수집을 직접 검증했다고 보고하지 않는다.

실제 키보드 시험에서 type=search의 Escape가 검색어만 지우던 문제를 추가 발견했다. 선택 본문에서 Escape를 처리해 검색어를 보존하고 한 번에 비교로 복귀하도록 고쳤으며 자동/직접 재검증했다.

## 검증과 한계

최종 `npm run check` 종료 코드0: 타입·포맷·번들/스킬, Python45·Node52·Chromium658+smoke2. 새 `tests/modal-navigation`26개가 일반 경로의 단일 native 모달·큰 팝오버 없음, 검색/비교 위치/확대·인라인 이름 오류/실제 IndexedDB 쓰기 실패/재시도·AI 초안/후보/배율/스크롤·연결 폼 소유 복원·사진/복구 뒤로·늦은 응답·문서 교체·전달 요청 초점을 검사한다. 기존 분기·주석·파일/저장·휴지통·AI/개발 전달 회귀도 통과했다.

기존 검사는 새 UI 의미로 갱신했다. 문서 이름은 인라인 입력, 원본 비교는 단일 작업 창의 본문, 결과 목록은 뒤로 경로·검색 보존을 확인한다. 수집 정보의 시각 점수 검사는 숨겨진 비교 배율의100% 옵션까지 세던 전체 textContent 대신 실제 정보 본문을 대상으로 한다. 검사 조건을 삭제하거나 실패를 성공으로 바꾸지 않았다.

스킬 quick_validate·새 AC106~110 중복 없음·문서 링크·125개 런타임 패키징을 확인했다. 가상 화면과 로그는 Git 제외 `local/modal-030/`의 `final-result-page.png`, `result-page-720.png`, `ai-connection.png`, `capture-info.png`, `check-final.log`다. README·스킬·앱 제공 가이드/런타임 ZIP도 같은 사용법이다.

이번은 웹/공통 검증이다. Electron IPC/네이티브 파일 저장·실제 IME/스크린리더·사용자 OS 업데이트/설치/재시작·외부 에이전트 인증·유료 AI를 새로 검증한 것은 아니다. 설치 배포 #27과 기존 실제 외부/AI 조건은 별도로 유지한다.
