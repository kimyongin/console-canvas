# 0.21.1 · 실제 사용성 점검 후속

2026-10-26 직접 브라우저 워크스루에서 발견한 7건을 #45~#51로 분리해 구현했다. 공통 UI 변경은 웹 검증으로 완료하는 [검증 기준](validation-policy.md)을 따른다. 설치된 앱을 교체하거나 실제 사용자 문서를 테스트에 사용하지 않았다.

## 저장 구조

`ai-draft.js`가 문구(8,000자 이하)·개수(1~12)·방식만 정규화한다. `editor-session.js`의 기존 저장 큐로 `sessions.aiDraft`에 저장하고 `openSnapshot` 및 파일 가져오기에서 복원한다. 기존 데이터베이스 스키마와 원본 캡처는 유지한다. 필드가 없는 기존 문서는 빈 초안으로 열린다. 초안 변경은 캔버스 undo나 스냅샷 편집 내용으로 기록하지 않는다. 키/모델 인증 상태는 초안·파일에 들어가지 않는다.

## 검증

- 가상 NORTH 콘솔과 테스트 전용 origin/프로필을 사용했다. 기존 0.21 테스트 문서를 새 번들로 다시 열고 선택 버전·세 후보·형제 스냅샷이 보존되는 것을 확인했다.
- 실제 브라우저에서 현재 밀도형 자동 선택, 다른 후보 전환, 마지막 적용 배지, 선택 요소 새 폼, API 설정 자동 노출/생성 비활성, 초안 문구·5개·API 방식을 입력한 뒤 창 닫기와 새로고침 복원을 확인했다.
- 실제 유료 API 추론·OAuth·외부 대화 자동 실행·설치 앱/OS 경계는 이번 변경의 검증으로 간주하지 않는다. #42/#44/#27의 잔여 범위는 유지한다.
- `npm run check` 종료 코드 0: TypeScript·포맷·빌드/스킬 패키징·Python 43·Node 33·Chromium 374개와 standalone/native-area smoke 2개 통과. AI 브라우저 검사는 38→52개로 확대했다.
- 초안의 새 렌더러/다른 문서/JSON 왕복, 비밀 필드 제외, 선택 대상 폼, 수동 전달 상태, 현재 후보/수동 편집 표시, API 준비 차단, 1280×720 및 700×600 레이아웃, 큰 저장 그래프 높이의 미리보기 공간을 확인했다. 기존 키보드 조절 검사도 현재 상한 안에서 조절되는지 확인한다.
- 스킬 `quick_validate.py` 통과. 최종 런타임 파일 106개(매니페스트 제외 체크섬 105개)·가이드/원본/스킬 ZIP 일치 확인. 로컬 로그: `local/ux-0.21.1-check.log`.
- 최종 번들에서 구분형 적용→실행 취소→밀도형 복원→갤러리 재진입 시 밀도형 자동 선택을 직접 확인했다.
