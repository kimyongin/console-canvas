# 변경별 검증과 완료 기준

2026-10-25 사용자 승인. 이 기준은 모든 기능·UI 변경마다 설치 앱을 교체하도록 하던 이전 지침을 대체한다. 웹 UI 완료, Electron 통합 확인, 사용자 설치 앱 배포를 각각 기록한다.

## 변경과 필요한 증빙

| 변경 범위 | 완료에 필요한 확인 | 별도로 수행하는 작업 |
| --- | --- | --- |
| 공통 편집기 UI·디자인·패널·레이어·주석·스냅샷·이력·비교·전달 화면 | 웹/공통 자동 검사와 영향받은 브라우저 사용 흐름 확인. 저장소/분기/파일 왕복 등 관련 회귀 검사 | 매번 설치 앱을 교체할 필요 없음 |
| Electron 수집·preload/IPC·네이티브 저장/클립보드·앱 종료/업데이트·스킬 설치·로컬 서버 경계 | 위 공통 검사와 영향받은 앱 통합 경로. 격리 프로필에서 자동화 가능한 범위를 먼저 확인 | 실제 OS 대화상자·IME·권한·업데이트 버튼 동작에 의존할 때 실제 OS 환경 확인 |
| MCP 계약·명령·가이드 제공 경로 | 관련 공통 검사와 공식 SDK 클라이언트 확인 | 웹 조회 결과를 실제 앱 MCP 연결 확인으로 간주하지 않음 |
| 설치 앱 배포 | 저장 응답·정상 종료·복구 가능한 백업 → 설치·재실행 → 기존 자료 보존·버전/화면·스킬/MCP 확인 | 사용자 설치 앱을 바꾸는 작업으로 별도 티켓에서 추적 |

하나의 변경이 여러 범위에 걸치면 해당 검증을 함께 적용한다. 웹 화면이 같다는 이유로 수정한 IPC·종료 경로 검사를 생략하지 않는다. 실제 한글 조합 입력·OS 클립보드·Chrome 권한·큰 문서 성능은 해당 환경에서 확인한 경우에만 통과로 기록한다.

## 명령

```sh
npm run check                  # 기본: 웹/공통
npm run check:web              # 같은 범위를 명시
npm run test:desktop           # Electron 통합만
npm run check:all              # 웹/공통 + Electron 통합
npm run test:desktop:offscreen # 표시 표면 없는 명시적 통합 대체 검사
```

기본 검사는 TypeScript → 포맷 → 번들·스킬 패키징 → Python → Node → Chromium UI 순서다. Chromium 실행에 Electron 개발 바이너리를 사용하지만 `desktop/main.cjs`를 통한 앱 설치·OS 캡처 검사는 포함하지 않는다. `check:all`은 통합 실패를 그대로 실패로 반환하며 offscreen으로 자동 전환하지 않는다. 잘못된 검사 옵션도 실패한다.

가상 NORTH 자료와 별도 임시 프로필·포트만 사용한다. 스크립트 성공만으로 직접 사용을 했다고 쓰지 않는다. 실행 명령·범위·결과·환경 제한을 함께 기록하며 소스 버전, 생성 앱 버전, 사용자 설치 버전을 구별한다.

## 티켓 종료와 미검증 이관

- UI 구현과 웹 검증이 끝났으면 UI 티켓을 종료한다. 설치 앱이 이전 버전이라는 이유만으로 계속 열어 두지 않는다.
- 기존 UI 티켓의 미확인 OS/통합·품질 조건은 [#7](https://github.com/kimyongin/console-canvas/issues/7), 설치·재실행·설치 스킬 조건은 [#27](https://github.com/kimyongin/console-canvas/issues/27)에서 추적한다. 이관은 통과를 뜻하지 않으며 원래 항목과 증빙을 보존한다.
- 원래 티켓이 앱 통합 기능 자체를 변경했다면 그 기능의 필요한 통합 검사는 계속 완료 조건이다. 단순히 티켓을 옮겨 검증을 없애지 않는다.
- Mac 잠금으로 실제 앱 배포를 확인할 수 없으면 배포 티켓만 대기한다. 웹 검증과 독립적인 작업은 계속한다. 사용자 앱을 강제 종료하거나 저장 확인 없이 덮어쓰지 않는다.

사용자 데이터 보호·일회성 자료 이전·저장 오류 처리·원본 웹사이트 격리 요구사항은 그대로 적용한다. 앱 배포 시 편집·주석 초안·추가 설명·전체 분기·휴지통과 개인 스킬 파일을 보존한다. 새 검증 기준을 과거의 네이티브 실패를 성공으로 바꾸는 근거로 사용하지 않는다.
