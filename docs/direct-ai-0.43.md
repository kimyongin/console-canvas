# 큰 자기 복제본의 직접 AI 호출 실패 · 0.43

2026-10-31 · #158 / FR-41·AC-144.

실제0.42.1에서 선택 모달을 정돈하려는 직접 호출4건이 토큰0·generation_invalid로 실패했다. 문서는13,037요소이고 HTML27,195,425자 중 인라인 computed style이25,410,989자다. 선택 부모 아래의 중첩 미리보기 DOM까지 입력이 포함돼 native22MB 검사에서 ChatGPT 전송 전에 거부됐고, 공통 provider의 코드2MB 제한에도 맞지 않았다. UI는 이를 키·모델·한도 문제로 안내해 같은 실패를 반복하게 했다.

직접 호출의 큰 입력에만 레이아웃 설명을 사용한다. 기존 data-uic-id·선택·부모/자식·원본 locator·주요 스타일/문구와 화면 이미지를 유지하고, 깊은/큰 하위 트리·긴 텍스트/속성·바이너리 자산 생략은 representation에 표시한다. 모델에 묘사된 ID만 편집하고 세부 수정은 생략 영역을 다시 선택하도록 안내한다. 원본 HTML/CSS·캡처·스냅샷·MCP 원문 조회는 바꾸지 않는다. 이 설명을 독립 렌더 가능한 전체 코드로 표시하지 않는다.

코드2MB/이미지15MB 제한은 직접 호출 공통 사전 검사로 통일했다. 입력·이미지·모델 카탈로그 오류를 구분하며 UI가 해당 복구 안내를 보여준다. native 검사와 API 키 경로 모두 전송 전 과대를 거부한다. 후속 호출의 로컬 실패도 먼저 완성된 후보와 실제 usage/model을 보존하고 반복하지 않는다.

## 검증 완료

가상 대형 문서의 선택/깊은 타깃·주요 스타일·예산/명시 생략·원본 비변경과 바이너리 분리10검사, ChatGPT UI23검사·기존 AI59검사를 통과했다. native 단위 검사에서 모델/코드/이미지 오류를 구분하고 과대 입력에 Responses 호출이 없음을 확인했다. 최종 `npm run check:all` 종료0: Python67·Node86·Chromium945+smoke2·타입/포맷/번들·스킬과 공식 SDK25+modern17·native scope5·실제 OS 암호화/정상 종료·재실행을 통과했다. 스킬 형식 검사도 통과했다.

실패한 실제 문서의 사본을 격리 프로필에서 같은 n40으로 선택했다. 직접 호출 경로에서243,444자 코드·683,694자 이미지·185요소·2개 생략 트리로 줄었고, 가상 transport의3후보가 등록됐다. 원본 캡처/현재 편집은 바뀌지 않았다. 이 단계는 실제 ChatGPT 추론으로 보고하지 않는다.

기존17문서·37스냅샷·주석3개와 실패 기록을 포함한 앱401파일·프로필238파일·스킬4파일을 정상 종료 후 지문 백업했다. 실제 자료는 Git 제외 local/direct-ai-failure-043에만 둔다.

## 실제 설치 앱의 같은 요청 재시도

공식 Electron45 SHA·기존 Apple 신원/DR·strict/deep 서명을 확인해0.43.0을 설치했다. 교체 직후 프로필238개 파일은 같고 앱403개·런타임133체크섬이 빌드와 같다. 실행 시 설치 스킬4관리파일이 자동 동기화되고 실제 MCP 가이드/SDK0.43.0으로 연결됐다. 추가 키체인 승인 없이 같은 ChatGPT 계정을 사용했다.

원본 문서를 바꾸지 않고 정확한 실패 기준의 새 진단 사본을 파일로 열었다. 같은 n40을 선택하고 같은 프롬프트·시안2개·AI 직접 호출/ChatGPT로 요청했다. gpt-6.1-sol의 두 후보가 모두 완료돼 실제 등록됐고 실패0이다. 입력150,387/출력3,509 tokens를 기록했다. 후보별로 reparent와 data-uic-id 대상 stylesheet가 반환됐으며 대상은 설명한 ID 범위 안이다. 실제 비교 창에서 두 후보를 전환하고 각각 렌더가 준비되는 것을 확인했다. 후보 생성/비교와 디자인 품질 판정은 구별하며 선택 적용이나 실제 앱 소스 디자인 변경은 하지 않았다.

정상 종료 후 생성 후보를 포함한 프로필238개 파일을 다시 백업했다. 오프라인 사본에서 저장 시각을 제외한 정규화 지문을 비교해 기존17문서의 캡처·전체 session·편집·주석·노트·타임라인/부모/휴지통·메타데이터가 전부 같음을 확인했다. 이전4실패와 과거 실제 AI 결과도 유지됐다. 암호화 계정 파일도 같다. 새 사본1개를 포함해18문서·38스냅샷·주석3개다.
