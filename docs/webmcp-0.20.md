도구 공개 토글은 Console Canvas의 native 도구 등록을 제어한다. 공식 Chrome DevTools MCP의 다른 브라우저 기능까지 제한하지 않는다. Chrome 단독 편집에는 Node·Python·별도 호스트가 필요 없지만 에이전트 측 공식 MCP는 Node 프로그램이다. 기존 앱/stdio/루프백 연결은 유지한다.

## 실제 실행

- macOS arm64, Node 24.21.0, Chrome 155.0.8059.85, 공식 Chrome DevTools MCP 1.12.0, 공식 MCP SDK 1.32.2. 개인 Chrome 프로필·실제 캡처·사용자 앱/설치 스킬을 사용하거나 변경하지 않았다.
- `npm run check`: TypeScript·포맷·번들·패키지, Python **40**, Node **30**, Chromium **321** 통과. standalone과 실제 브라우저 영역 드래그도 포함한다.
- `npm run test:desktop:offscreen`: 기존 앱 공식 SDK **22**, sandbox/원본 DOM 비변경, 정상 종료/재실행 뒤 편집·주석·스냅샷/휴지통·이름·패널 보존 통과. 실제 OS 캡처/설치 창 직접 사용 증빙은 아니다.
- `node experiments/webmcp/run.mjs --product`: 실제 Chrome 확장 액션 수집과 제품 native 도구의 **55개** 검사 통과. 최종 `console-canvas-chrome.zip`을 그대로 풀어 설치하고 SHA-256을 보고서에 남긴다. 실험용 adapter.js나 Python 스키마 추출은 사용하지 않는다.
- `--product --headed`: 별도 프로필의 일반 Chrome 창에서도 같은 55개 자동 검사를 통과했다. 실제 OS IME·사용자 권한 대화상자·일반 사이트 자원 검증을 대신하지 않는다.
- 스킬 quick_validate 통과. 원본 SKILL.md·가이드·전체 helper ZIP·Chrome ZIP의 내용/버전과 공개 자산 체크섬을 확인한다.

공통 검사 최초 병행 실행 중 selection 문서 전환에서 한 번 타임아웃이 발생했다. 단독 재실행과 최종 전체 검사는 통과했다. 원인을 제품 버그나 환경 문제로 확정하지 않으며 재현되면 별도 조사한다. 초기 이미지 검사에는 같은 경로의 이전 미리보기 탭을 선택하는 테스트 결함이 있었다. 탭 닫기·정확한 blob 출처·PNG 원본 크기 대조를 추가한 뒤 10개 번호/카드와 삭제 전 참고를 직접 열어 확인했다. 이전 잘못된 캡처를 새 증빙으로 사용하지 않는다.

## 검증한 동작과 실패

공식 SDK→공식 Chrome MCP→격리 Chrome→확장의 `document.modelContext`→공통 controller 순서로 다음을 확인했다. `evaluate_script`는 공개 동의 버튼·오류 주입·상태/원본 DOM 관찰에 사용하고 실제 편집 명령은 `execute_webmcp_tool`을 통해 실행했다.

- 실제 HTTP NORTH 콘솔 수집, 300개 이상 요소와 원본 URL/버튼 locator 유지, 원본 DOM SHA-256 동일·업무 이벤트 0.
- 이동/주석 묶음 한 undo 단계와 저장, 동일 ID 키 순서가 달라도 재적용하지 않음, 다른 인수·오래된 revision·잘못된 editor_id 거절.
- undo/redo·공통 영구 이력, A→B→C 및 A→D의 실제 parent_id·미래 C 복원, 새로고침 뒤 주석·전체 가지 보존.
- 공개 해제 시 공식 discovery에서 도구 제거, 문서 닫기 자동 철회, 새로고침 이전 세대 명령 거절, 캡처 전 공개 가이드와 빈 화면 목록, 미지원에서도 일반 편집 준비.
- 잘못된 작업 묶음의 부분 적용 없음, 사람 모달 입력 중 busy, IDB quota 오류에서 적용 성공과 `persisted:false/save_error` 구별, 스냅샷 저장 오류에서 화면/버전/revision 롤백.
- 현재/저장 버전 이미지가 편집·active/preview·revision·이력/undo를 바꾸지 않음. 주석만 1개, 10개 요청 및 삭제 전 참고, 현재와 다른 저장 버전의 10개 요청 PNG를 실제 MCP `image/png` 콘텐츠로 수신하고 열어 확인.

JS/Python 계약 일치·잘못된 자료형/한도·동시 재시도·철회한 핸들/다른 문서 접근은 단위 검사도 유지한다. 이미지 생성 실패·20MiB 초과·렌더 중 revision 변경은 공통 controller 단위 검사에서 확인한다. 폴링 작업은 실패/완료 시 제거하므로 같은 revision의 재요청이나 만료된 미리보기가 영구 캐시되지 않는다.

## 남은 완료 조건

**#33:** 외부/인증 이미지·웹폰트·SVG·iframe/래스터·표/스크롤에서 COOP/COEP 영향을 확인한다. 실제 activeTab 거부·수집 중 탭 전환·제한 페이지·브라우저 재시작, 한글 입력/포커스를 추가 검증한다. 일반 창 자동화 통과를 이 조건의 통과로 표시하지 않는다.

**#35:** 고정 ID의 이전 실제 버전→0.20 업데이트 전후 문서·초안·설명·복사·이력·전체 분기/휴지통/환경 지문을 검증한다. 앱↔확장 실제 JSON 양방향 왕복과 실패 복구, 스토어 ID/서명 키 채널·아이콘/제출 자산을 마무리한다. 새 경로 설치·새 ID를 기존 저장소가 유지되는 업데이트라고 설명하지 않는다. 현재 ZIP은 개발자용이며 스토어 미게시·미승인이다.

**#7/#27:** 기존 OS/Electron 품질 잔여와 사용자 앱 설치 배포는 계속 별도 추적한다. 사용자 앱을 저장 확인 없이 덮어쓰거나 강제 종료하지 않는다.

로컬 재현 자료는 Git 제외 경로 `local/webmcp-experiment/product-*-report.json`, `agent-*.png`, `local/webmcp-release-*.log`에 있다. 실제 사이트 캡처·개인 프로필·토큰을 커밋하지 않는다. 구현 코드와 재현 검사는 저장소에 포함한다.
