## 조작과 보존

- 기존 맞춤/100%/선택 요청 위치 조작을 유지하고 새 모드나 확인 단계를 추가하지 않았다. 라벨과 버전 기준은 기존 자리에서 읽는다. 버전 조회/저장 부모 확인에 별도 창을 요구하지 않는다.
- 두 비교 프레임만 내부 스크롤하고 요청 탐색/푸터·닫기는 그대로 유지한다. 키보드 초점 표시를 제공한다. 수동 탐색을 계속 자동 초기화하거나 원본 렌더 너비를 좁은 프레임 너비로 바꾸지 않는다.
- 결과 교체·미리보기는 기존 캔버스/분기/리뷰 판정과 분리한다. 새 결과가 저장됐다는 사실과 비교 DOM이 실제로 준비된 시점을 구분한다. 다른 결과 선택은 기존대로 별도 검토다.
- 저장 순번 vN은 타임라인 전체의 원래 순서로 계산한다. 휴지통 포함 기존 항목을 재정렬/제거하거나 날짜/과거 이력을 새로 만들지 않는다. 미리보기에서 A를 골랐더라도 실제 기준이 B면 새 저장 부모는 B다.
