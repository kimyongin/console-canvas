# iframe 가져오기 · 0.23.0

접근 가능한 iframe은 내부 DOM을 펼쳐 복제한다. 버튼·문구 등의 `data-uic-id`는 문서 전체에서 고유하며, 원본 selector/ID와 `locator.frames`의 프레임 경로를 유지한다. 중첩 5단계·총 32개 프레임과 전체 요소 한도를 적용한다. 원본 스크립트와 iframe을 실행하지 않고 계산 스타일과 비활성 div로 렌더한다.

내부 DOM을 읽을 수 없는 iframe은 활성 원본 화면의 스크린샷에서 보이는 영역만 잘라 이미지 한 레이어로 넣는다. 통째로 이동·삭제·복사·주석을 지원한다. 일부만 보인 경우 해당 부분의 원래 위치와 크기를 유지하고 화면 밖 영역은 채우지 않는다. 레이어 이름은 ‘요소’와 ‘이미지’, 속성에는 부분 이미지 여부를 표시한다. 이미지 내부 요소의 개별 편집은 지원하지 않는다.

캡처 중 탭·주소·뷰포트·스크롤 변경을 감지하면 잘못된 이미지 대신 경고와 재수집 안내를 제공한다. 자동으로 원본을 스크롤하거나 보이지 않는 내용을 만들지 않는다. 다른 출처의 DOM 수집을 위한 새 사이트 권한은 추가하지 않았다. 허용 범위 확대와 일반 사이트 전체의 격리/리소스 조건은 #33에서 별도로 추적한다.

## 검증

`tests/iframes.html`의 19개 검사는 실제 Chromium 격리 월드와 제품 `desktop/capture.cjs`를 통해 가상 화면을 캡처한다. 동일 출처·중첩·내부 스크롤·고정 요소, opaque sandbox의 접근 불가 화면, 전체/부분/화면 밖 이미지, 실제 이미지 픽셀, 부모 이동/삭제·주석·저장/재열기를 확인한다. 원본 DOM·스크롤과 업무 이벤트 횟수가 변하지 않는지도 검사한다. 사용자 설치 앱의 OS 화면 수집 및 모든 외부 사이트를 검증했다는 의미는 아니다.
