# iframe 가져오기 · 0.24.0

기본 가져오기에서 각 iframe의 DOM을 먼저 수집하고 성공 결과를 개별 요소로 합친다. 내장 Chromium은 OOPIF 컨텍스트와 실제 소유 요소를 사용한다. Chrome은 허용된 컨텍스트 전체를 시도하며 권한/신원이 불확실한 프레임은 잘못 매칭하지 않고 원인을 남긴다.

실패하거나 수집 중 내용이 바뀐 프레임만 이미지 한 레이어로 보존한다. 자동 스크롤·타일 촬영으로 긴 영역을 보완하고 원래 위치를 복원한다. 미렌더링 가상 콘텐츠는 생성하지 않으며 부분·미수집 이미지는 구분한다. 프레임 경로와 원본 식별자는 유지한다.

[구현·한도·95% 검증 방법](capture-quality-0.24.md), [티켓/최종 상태](capture-quality-plan.md)를 따른다. 0.23의 현재 뷰포트 부분 이미지 보존만으로 전체 수집 성공을 주장하지 않는다. 설치 앱·일반 Chrome 권한·스토어 배포를 각각 구분한다.
