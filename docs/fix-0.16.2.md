# 0.16.2 전달·스냅샷 UX 수정

2026-10-25. 직전 실사용에서 발견한 4개 문제를 수정했다. **소스·배포 앱 빌드·별도 브라우저 직접 사용 검증 완료, 사용자 설치 앱의 교체/재실행은 미완료**다. 사용자 앱은 0.16.1을 유지한다.

## 변경

- 전달 모달은 본문 한 곳만 스크롤한다. 복사·PNG 저장·상태 메시지는 하단 고정 영역에 남는다.
- 스냅샷 이름 변경 저장/취소 후 같은 그래프를 다시 열고 미리보기 선택·가로/세로 스크롤·항목 메뉴 포커스를 복원한다. 실제 작업 기준 버전은 바꾸지 않는다.
- PNG 제목은 정상 36px 글꼴로 여러 줄에 걸쳐 표시하고 화면·카드 시작 위치도 아래로 이동한다. 가로 압축은 사용하지 않는다.
- 삭제 전 참고 화면은 복사본의 캡처 정보를 유지해 원래 기준 위치에 표시한다. 참고/현재 화면의 전체 크기를 포함해 렌더링하므로 삭제 후 화면 크기 감소로 참고 영역이 잘리지 않는다. 참고 장면 생성은 finally에서 편집·주석·선택을 복원한다.

PRD·README·스킬 원문과 번들 가이드를 함께 갱신했다. 기존 저장 데이터 형식과 MCP 명령 계약은 바꾸지 않았다. 스킬 런타임 ZIP과 앱용 ZIP은 빌드가 다시 생성했다. 현재 설치된 스킬을 새 버전으로 동기화하는 단계는 사용자 앱 갱신과 함께 남아 있다.

## 검증

- 최종 `npm run check`: 타입·포맷·빌드, Python 39개·Node 24개·Chromium 262개 통과. 표시 표면 캡처 단계는 `Current display surface not available for capture`로 실패했으며 전체 성공으로 표시하지 않는다.
- evolution 회귀 검사 5개를 추가했다: 이름 변경 후 그래프/선택/스크롤/포커스 복귀, 720px에서 출력 버튼 노출, 삭제 복사본 참조 노드/전체 크기, 참고 렌더링의 편집/주석/선택 불변, 긴 제목의 여러 줄/가로 압축 없음.
- 최종 배포 앱을 지정한 offscreen 검사에서 실제 공식 SDK 22개·정상 종료/재실행·문서명/주석/스냅샷/휴지통/패널 보존을 확인한다. 실제 표시 표면 캡처만 명시적 가상 화면으로 대체한 범위다.
- CUA 브라우저에서 새 가상 NORTH 문서만 직접 사용했다. 긴 문서명 변경→버튼 복사/붙여넣기/삭제→스냅샷 저장/이름 변경→그래프 복귀→PNG 실제 클립보드 복사/파일로 열기를 수행했다.
- 720px 화면에서 복사/저장 버튼 하단 637.2px, 모달 하단 683px이었다. 모달 scrollHeight/clientHeight 모두 646px으로 별도 바깥 스크롤 없이 버튼이 보였다. 실제 PNG에서 제목 줄바꿈과 삭제한 복사본 버튼 전체를 확인했다.

증빙은 Git 제외 `local/fix-0.16.2-complete-check.log`, `local/fix-0.16.2-offscreen-final.log`, `local/fix-0.16.2-review.png`, `local/fix-0.16.2-modal.png`와 `local/fix-0.16.2-build-final.log`에 있다. 앱/ZIP/DMG는 `dist/`에 생성한다.

## 설치 상태

CUA가 Mac 잠금으로 설치 앱 창의 조작을 거절했다. 기존 앱 프로세스를 강제 종료하거나 사용자 프로필을 시험 앱으로 열지 않았다. 저장소의 정상 종료·백업·설치 갱신·실제 재실행 완료 기준 때문에 앱 교체와 설치 스킬 자동 동기화를 완료 처리하지 않는다. 잠금 해제 후 기존 앱의 초안 저장/정상 종료·백업·새 앱 설치·재실행·기존 자료 보존 확인이 남아 있다. 새 빌드는 별도 프로필에서만 검증했다.
