## 세 경로와 공통 결과

| 경로 | 입력/실행 | 결과 | 인증 |
| --- | --- | --- | --- |
| 사용자 직접 편집 | 선택·드래그·삭제·복사·주석 등 현재 제공된 조작 | 같은 캔버스의 현재 작업 | AI 인증 불필요 |
| AI 직접 호출 | 현재 HTML/CSS·화면·프롬프트를 제공자 API에 전달 | 수정 코드 또는 패치 → 독립 HTML/CSS 시안 | API 키 또는 지원·자격이 확인된 ChatGPT 로그인 |
| 외부 로컬 에이전트 MCP | 사용자가 에이전트에게 프롬프트 전달 → MCP로 코드/요소/주석 조회·편집 | 같은 캔버스에 후보 등록 | 해당 에이전트의 인증과 별도의 문서 MCP 공개 |

API 키와 ChatGPT 로그인은 두 번째 경로의 **인증 선택지**다. 네 번째 편집 모드가 아니다. 모델 API는 판단/생성을 요청하는 통로이고 MCP는 편집 도구를 노출하는 통로다. API 내부의 도구 실행은 공통 엔진을 직접 호출하거나 검증한 MCP 어댑터를 사용할 수 있다. 외부 MCP 왕복을 API 편집의 필수 조건으로 두지 않는다.

모든 경로가 문서·안정 요소 ID·원본 식별 근거·패치·주석·undo/redo·통합 이력·분기 스냅샷·저장·편집 JSON·PNG를 공유한다. 경로별 별도 저장소/이력을 만들지 않는다. 원본 웹사이트와 프로젝트 소스는 수정하지 않는다.

## 코드 입력/수정 출력과 시안 선택

1. 사용자는 요소/영역을 선택하고 ✨ 시안 만들기에서 실행 경로를 고른다. 주석/프롬프트는 선택적으로 입력하고 기존 주석을 우선 반영한다.
2. 기준을 고정해 현재 코드·선택 요소/필요 부모·관련 CSS와 화면 이미지를 준비한다. 전체 문맥이 필요한 경우 확장할 수 있으나 전체 HTML/CSS를 매 요청마다 보내는 것으로 고정하지 않는다.
3. API는 수정 코드/패치를 반환한다. 선택적 도구 호출 반복이면 필요한 부분을 추가 조회하고 적용/렌더 이미지를 다시 읽어 보정한다. 자격 증명은 프롬프트나 도구 결과에 넣지 않는다.
4. 수정 코드를 정제·검증해 독립 후보로 렌더한다. 스트리밍의 미완성 코드를 현재 문서에 적용하지 않는다. 임의 JavaScript 실행으로 편집을 구현하지 않는다.
5. 처음에는 같은 기준에서 세 가지 대안을 검증하되 개수는 고정 한도가 아니다. 자동 호출/외부 에이전트 모두 동일한 갤러리에 이름·방향·차이·실제 미리보기를 반환한다.
6. 사용자가 하나를 명시적으로 선택해야 현재 작업에 적용한다. 후보는 형제 분기로 보존하고 현재 미저장 작업 보호·한 undo 단계·다른 후보 재선택을 제공한다.

자동 실행이 안 되는 외부 에이전트 경로는 요청 문장을 한 번 복사·붙여넣는 대안을 사용한다. MCP가 없어도 AI 직접 호출은 가능하도록 설계한다. API 직접 호출과 MCP 모두 사용하지 않으면 기존 PNG 첨부/시안 이미지 수동 비교는 가능하지만 편집 가능한 후보 자동 복귀로 표시하지 않는다.

## API 키와 ChatGPT 로그인

| 항목 | API 키 | ChatGPT 로그인 |
| --- | --- | --- |
| 인증 | 사용자가 발급한 제공자 키 등록/검증/교체/삭제 | 공식 Continue with ChatGPT·OAuth 동의·구독 사용 권한 확인 |
| 사용/과금 | 일반 API 사용량 과금 경로로 표시 | 적격 요청이 구독/사용 가능한 크레딧을 사용. 한도/모델/계정 접근은 실제 확인 |
| 필수 검증 | 실제 요청 완료·취소/오류·키 보관과 비노출 | 제품/계정 자격·동의·권한·실제 추론·갱신/철회·로그아웃 |
| 미지원/한도 | 원인과 복구 방법 표시, 사용자 자료 보존 | 재로그인/사용량 관리 또는 사용자가 API 키/외부 에이전트를 명시적으로 선택 |

2026-10-26 확인한 **OpenAI Docs**는 적격 Plus/Pro와 로컬 오픈소스/개인 프로젝트에 구독 사용을 위한 OAuth 경로를 설명한다. 유료/원격 호스팅 배포는 별도 접근 조건이 있다. 공개 저장소라는 사실만으로 적용 자격을 확정하지 않는다. 현재 저장소에서 루트 LICENSE 파일을 확인하지 못했으며 라이선스/배포 형태·약관과 실제 계정 자격을 #44에서 확인한다. 사용자 대신 라이선스를 임의 선택하지 않는다. [공식 로그인 안내](https://developers.openai.com/siwc/quickstart), [적용 조건](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)

구독용 API 키를 발급받아 붙여넣는 기능으로 설명하지 않는다. 로그인 성공·모델 목록 조회·구독 사용 권한·완료된 실제 추론은 각각 다르다. 구독에 모든 모델/기능/무제한 사용이 포함된다고 약속하지 않는다. API 키와 구독 인증 사이에서 자동으로 과금 경로를 전환하지 않는다.

구독 사용의 현재 제한에는 `store:false`·`stream:true`, 지원 입력/도구와 hosted MCP 비지원 등이 있다. 로컬 도구 실행은 hosted MCP와 구별한다. 정확한 API 필드/모델 지원은 구현 시 다시 확인하며 인증 방식별 제공자 계약으로 처리한다. [현재 제한](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)

키/토큰은 신뢰한 앱 경계와 검증한 저장소에서 관리한다. 캡처 iframe·모델 문맥·로그·이미지·편집 JSON·스냅샷·스킬에 포함하지 않는다. 다른 앱의 로그인 파일을 읽거나 토큰을 추출해 인증을 대신하지 않는다. 데스크톱/확장의 비밀 보관·redirect/loopback·권한 조건은 별도로 검증한다. 인증 실패나 로그아웃이 편집 문서/후보를 지우지 않는다.
