## Electron·공식 SDK

격리 프로필/브리지/스킬 디렉터리에서 공식 SDK16, 2026-07-28 SDK6, 이미지 스크롤 상세8·수집 범위5 검사를 통과했다. 실제 DOM+fixture 사진/offscreen 조건이며 수동 설치 앱 사용을 의미하지 않는다.

MCP 실제 image 블록·ID/이름 조회·편집/재시도·같은 ID 확정·구현 지시/증빙/승인 guard·허용 범위와 resource 알림, 파일 PNG 저장·스킬 설치·정상 종료/재실행 후 편집/주석/복사/고정 목표/기록을 확인했다. 구현/검토 이미지는 가상 QA 자료이며 외부 에이전트의 실제 프로젝트 디자인 구현 성공으로 표시하지 않는다.

## 중간 실패와 수정

- 사후 등록·문서 전용 테스트를 새 티켓 생성/목록/같은 ID 확정 테스트로 대체. 비동기 저장/모달 표시를 기다린 뒤 실제 UI 상태를 검사하도록 변경.
- 이미지 생성 중 revision 변경은 blob 인코딩 전에도 감지해 이전 결과를 최신으로 내보내지 않는다.
- 미허용 프로젝트를 앱 미연결로 잘못 안내하던 브로커 응답을 구별했다.
- 티켓 상태 갱신의 workspace revision을 poll에 실어 resource 구독 알림을 복구했다. 읽기만으로 변경 알림을 누적하지 않는다.

## 액션 수와 UX

클릭·메뉴 펼치기·링크 이동·앱/대화 왕복을 각각 한 동작으로 센다. 문장 입력은 하나의 입력 동작으로 세되 키 수와 요청 제출 횟수는 별도다. 아래는 로그인·최초 MCP/공유 연결이 끝난 상태의 표준 경로이며 가변적인 편집 횟수는 별도다.

‘모든 기능이 두 클릭’이라고 주장하지 않는다. 원본 사이트 주소 입력·로그인/메뉴 펼치기·필터 조작은 원본 상태에 따라 추가되며 생략하지 않는다. 앱↔대화 이동도 실제로 이동했으면 별도 1회로 기록한다. 모호한 이름의 선택·공유 허용·목표 확정·구현 지시·실제 승인은 안전/의도 보장을 위해 유지한다.

## 설치·실제 사용·가이드

- 변경 전 0.45.2 앱·프로필 전체·설치 스킬을 로컬 private 백업했다. 캡처/로그인/개인 파일은 Git에 포함하지 않았다.
- 같은 Apple Development 신원으로 0.46.0 앱·DMG를 빌드·검증하고 정상 종료 후 설치 앱을 갱신했다. 프로필은 초기화하지 않았다. 기존 편집·주석·확정 목표가 v3로 이전됐다.
- 설치 앱에서 새 티켓 CC-5를 만들고 이름/프로젝트 변경·샘플 부착·선택 요소 주석을 실제로 작성했다. 최종 수정본 재설치/정상 재실행 뒤에도 같은 ID와 주석이 유지됐다. 설치 스킬의 SHA-256은 소스 스킬과 일치했다.
- 새 공식 SDK 연결로 설치 앱 0.46.0·16 도구·guide-console 프로젝트·CC-5 ID/정확한 이름·주석1·실제 이미지2를 확인했다. 실제 MCP로 CC-5를 같은 ID의 구현 대기/고정 goal로 확정했다. 재실행 후 조회로 보존을 확인했다.
- 네이티브 AX 클릭 일부는 화면 변화가 없어 완료로 세지 않았다. 열린 편집/모달 중 MCP 쓰기가 거절됐고 정상 재실행 뒤 동일 작업이 성공했다. 재연결 직후 이전 lease가 살아 있는 동안 ambiguous_workspace가 발생했으며 만료 후 한 작업 공간으로 정상 연결됐다. 이 보호를 우회하거나 사용자 자료를 삭제하지 않았다.
- 공통 편집기에서는 CC-2 생성→같은 티켓에 샘플→이동→주석/공통 설명→공유→같은 ID 목표 확정을 직접 사용하고 실제 화면7장을 찍었다. 설치 앱 실제 화면1장도 가이드에 포함했다. 웹에서 목표/목록 모달·공유 체크박스 유지, 가이드 390px/데스크톱·확대/닫기·복사를 확인했다.
- [사용 가이드](https://console-canvas-guide.yonginkim.chatgpt.site/)와 [개념 문서](https://console-canvas-concept.yonginkim.chatgpt.site/)를 기존 접근 범위 그대로 재발행했다. 가이드 소스 3f588e2d7bf397e6b4daf153ecf426998c0af92d, 개념 소스 27904429061db2daf6b094cefc2a842e1ca7ad89.
