## 기존 티켓과의 관계

| 기존 티켓 | 처리와 남은 책임 |
| --- | --- |
| #36~#44, #149 | 남은 앱 직접 AI/후보/분기·자동 실행 계획은 제품 방향 변경으로 종료(not planned). 과거 구현·조사·검증 본문은 보존한다. 필요한 이미지 맥락/직접 편집은 #166으로 재정의하며 #163/#164의 실제 제거가 완료된 뜻은 아니다. |
| #152 | 열림 유지. 일반 앱 라이선스·공개 배포 잔여만 재정리해 #168과 연결한다. 폐기한 앱 직접 AI 제공자의 인증/추론/배포 적격 검증은 신규 목표에서 제외한다. 기존 성공·미검증 증빙은 보존하고 법적 적격/공개 배포 완료를 추정하지 않는다. |
| #7 | 일반 OS 입력·파일/클립보드·성능 등 실제 미완료 통합 조건을 계속 추적. Chrome 확장이나 제거 기능을 다시 구현할 요구로 사용하지 않는다. 새 범위의 설치 완료는 #168에서 확인한다. |
| #68/#73 | 원본 수집의 일반화·동적 화면 품질 과제는 유지한다. 화면 간소화로 해결됐다고 표시하지 않는다. |
| 이미 종료한 과거 티켓 | 재개/재구현하지 않는다. [0.44 티켓 기록](ticket-review-0.44-history.md)과 버전 증빙을 유지한다. |

## 검증과 잔여

[0.45 검증 기록](simplification-0.45.md)에 정상·실패·사용 흐름, 원본 품질과 공식 SDK를 구분해 기록한다. 앱 설치는 정상 종료 후 같은 Apple 개발 서명으로 수행하고 새 문서/티켓·MCP·관리 스킬을 확인한다. 테스트 자료 초기화 면제는 웹 로그인·OS 서명·개인 스킬 삭제 승인이 아니다.

과거 0.44 성공을 새 흐름의 검증으로 쓰지 않는다. 원본 재현 일반화 #68/#73, 통합 잔여 #7과 일반 공개 배포 적격 #152는 별도 범위를 유지한다. 외부 에이전트의 실제 이미지 추론을 앱의 내장 기능으로 표시하지 않는다.
