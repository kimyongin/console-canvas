# PRD 기준 티켓 재검토

검토일: 2026-10-25. 기준: 0.15.0의 [PRD](PRD.md), [기능 전수 대조표](feature-audit.md), [검증 기록](verification.md), GitHub의 전체 이슈 #1~#11.

기존 11개 이슈의 제목·본문·의존성·완료 조건을 대조해 갱신했다. 새 이슈를 늘리지 않았고 모두 열린 상태다. 이 문서는 실행 계획의 정리이며 결함 수정·React 도입·새 앱 배포 완료를 뜻하지 않는다.

#8→#9→#10→#11은 추천 착수 순서다. #8/#9/#10은 서로 기술적 선행 조건이 아니며 #11은 #10의 보호/백업 계약과 먼저 맞춘다. 결함 수정은 React를 전제하지 않는다. #2의 빌드 준비는 먼저 진행할 수 있지만 사용자 편집을 담당하는 React 경로 활성화는 0단계 검증 이후다. 이후 #2→#3→#4→#5→#6→#7로 진행한다. 역방향 선행 조건이나 순환 의존성은 없다.

결함 티켓은 기존 코드의 오류 정책과 커밋할 회귀 검사를 책임진다. #3은 그 정책을 노출하고 #5/#6은 UI에 연결한다. #7은 최종 검증을 통합하며 결함 수정이나 앞 단계의 누락 기능을 대신 구현하는 티켓이 아니다. 같은 변경의 증빙은 원 담당 티켓으로 연결한다.

## 범위와 완료 판정

- 원본 사이트를 React로 재작성하지 않는다. DOM/이동 엔진·Electron·Python MCP·IndexedDB·이미지 생성기는 기존 구조를 재사용한다.
- 오른쪽은 탭 없는 변경 이력이다. #5는 패널 틀/이름/접근성을, #6은 콘텐츠를 담당한다. 요소/좌표 주석은 #5의 모달이며 추가 설명·비교·전달은 #6이다.
- 그래프 미리보기는 조회이고 적용은 명시적 명령이다. UI 이름 저장 후 자동 열기와 MCP create_snapshot의 기존 비강제 UI 동작을 구별한다.
- 에디터는 snapshot/review JSON을 입력한다. CLI review의 ZIP 지원·PNG 결과·전체 프로필 백업을 에디터 파일 입력과 혼동하지 않는다.
- undo는 세션 최근 100개이며 문서 재열기/전환·앱 재시작 후 초기화된다. 영구 이력/스냅샷을 undo 영구 저장으로 해석하지 않는다.
- PNG 파일 저장, 클립보드, MCP 이미지 응답은 별도 경로로 확인한다. 이미지 크기 한도 초과를 자동 분할 제공으로 확대하지 않는다.
- 각 결함에는 가상 데이터의 정상/실패 회귀 검사를 커밋한다. Git에서 제외한 local probe만으로 재현 책임을 끝내지 않는다.
- 앱/UI 변경 시 초안 저장·정상 종료·앱/프로필 백업 후 설치 앱 갱신/재실행을 수행한다. 실제 사용자 문서에는 테스트 편집을 하지 않는다. 저장 형식 변경 시에도 검증된 왕복/일회성 이전으로 자료를 보존한다.
- 업데이트 버튼 검증과 수동 설치 교체를 구분한다. 설치 스킬 동기화/개인 파일 보존, 실제 설치 앱 활성 화면 MCP 조회가 완료 조건에 포함된다.
- 잠금/권한·환경으로 못 한 검사는 대체 검사·남은 조건을 기록하고 체크하지 않는다. 0.15.0의 289개 정상 검사와 별도 SDK 22개 성공은 표준 전체 검사·최신 설치 창 사용 완료가 아니다.

이 계획 검토 당시에는 문서만 변경했고 앱 버전은 0.15.0, #8~#11은 미수정이었다. 이후 0.16.0 소스 구현·오류/React 회귀 검사와 조건부 MCP/재실행 검증을 진행했다. 설치 창 등의 잔여가 있어 티켓은 계속 열려 있다. 실제 검증 결과는 [검증 기록](verification.md)에 남기며 여기의 계획표를 실행 결과로 취급하지 않는다.

## 이번 문서·티켓 검토의 확인 결과

- GitHub #1~#11을 갱신한 뒤 다시 조회해 제목/본문 반영과 열린 상태를 확인했다. 완료 체크는 추가하지 않았다.
- 기능 17개·품질 6개·수용 기준 18개의 담당 행, 11개 이슈 링크·문서 상대 링크와 요구사항 ID 범위를 확인했다. 실행 의존성에 순환이 없다.
- npm 실행 파일이 없는 환경이므로 같은 스크립트인 `node scripts/check.mjs`를 Node 24.21.0 / Electron 45.0.0 arm64로 직접 실행했다. 포맷·빌드·Python 39·Node 23·Chromium 227개가 통과했다.
- 전체 스크립트는 데스크톱 캡처의 `Current display surface not available for capture`에서 종료 코드 1로 중단됐다. 이번 실행은 이후 설치 앱/SDK 단계나 실제 창 사용의 새 증빙을 만들지 않았다. 전체 통과로 기록하지 않는다.
- 실행 로그는 Git 제외 경로 `local/ticket-review-2026-10-25/check.log`에 있다. 런타임/스킬 생성물의 추적 파일 차이는 없고 앱 설치/사용자 프로필은 변경하지 않았다.
