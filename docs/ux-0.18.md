# 0.18.0 UX 후속 개선

2026-10-25. 직접 사용 후 제안한 다섯 개선을 구현했다. **소스·배포 빌드·별도 가상 문서의 브라우저 직접 사용은 검증했고, 설치된 사용자 앱 갱신·재실행은 남아 있다.** Mac 잠금으로 기존 앱의 정상 저장·종료를 확인할 수 없어 설치 앱과 설치 스킬은 0.16.1을 유지했다. 실제 사용자 문서에는 QA 편집을 적용하지 않았다.

최근 스냅샷은 휴지통/자동 보관을 제외한 최근 저장 항목이다. 현재 작업 기준 스냅샷과 다를 수 있다. 변경 건수는 기준 버전과 다른 요소/주석 ID 수와 추가 설명 차이 한 건이며, 같은 요소의 이동과 주석은 한 건으로 센다. 선택·이력 위치·레이어 별칭은 제외한다. 픽셀 diff나 시간순 작업 횟수와 다르다.

## 데이터·MCP·스킬

- 캡처·편집·분기·주석·추가 설명·휴지통 구조는 유지한다. 썸네일 HTML을 DB에 추가 저장하지 않는다. 원본 캡처는 변경하지 않는다.
- `documents` 목록 메타데이터에 작은 `snapshotName`·`commentCount` 요약만 저장한다. 기존 문서를 읽기 위해 파괴적 이전이나 원본 재수집을 요구하지 않는다.
- MCP는 기존 13개 도구와 원본 locator·revision/operation_id·dirty/persisted 계약을 유지한다. 새 UI의 비교/탐색으로 MCP revision을 올리지 않는다.
- PRD FR-04/05/06/11/15와 AC-19~23, README, 스킬 원문·가이드·확장 런타임 ZIP·앱용 스킬 ZIP을 갱신했다. 격리 프로필의 설치/동기화는 확인했고 실제 설치 스킬 동기화는 사용자 앱 갱신과 함께 남아 있다.

## 검증 상태

- 저장 오류 중에도 문서 목록은 조회할 수 있고 오류 안내를 유지한다. 비교/상태의 차이 계산은 같은 정규화를 사용해 0 오프셋이나 키 순서만 다른 항목을 변경으로 세지 않는다.
- 타입·포맷·빌드, Python **39개**, Node **27개**, Chromium **302개** 통과. 기존 286개와 새 followup 16개다. 최종 앱 번들의 런타임을 지정한 Chromium 검사도 302개 통과했다.
- 최종 앱에 공식 MCP SDK **22개** 연결 검사, 네이티브 PNG 저장, 격리 스킬 설치·ZIP·정상 종료/재실행과 문서명·주석·스냅샷/휴지통·패널 복원을 확인했다.
- 표준 `npm run check`는 마지막 네이티브 화면 수집에서 `Current display surface not available for capture`로 실패했다. `test:desktop:offscreen`은 실제 DOM/가상 스크린샷 조건으로 통과했으며 일반 설치 앱의 직접 사용 완료로 간주하지 않는다.
- CUA 브라우저에서는 별도 가상 문서로 도구창·문서 목록·비교 확대/변경 탐색/마우스 동기 스크롤·2개 주석의 이전/다음·재열기를 직접 사용했다. macOS IME와 잠긴 일반 앱 화면 검증은 포함하지 않는다.
- 공식 Electron SHA-256 확인 후 앱·ZIP·DMG를 생성했고 DMG 검증이 통과했다. [AGENTS.md](../AGENTS.md)의 “종료·업데이트는 `desktop/lifecycle.cjs`의 같은 저장 응답을 기다린다”와 정상 종료/백업 기준에 따라 잠긴 사용자 앱은 강제 종료하거나 교체하지 않았다. 티켓의 설치 완료 항목은 미완료로 유지한다.

Git 제외 증빙: `local/ux18-check.log`, `local/ux18-packaged-browser.log`, `local/ux18-sdk.log`, `local/ux18-desktop-build.log`, `local/ux-0.18-inspector.png`, `local/ux-0.18-compare.png`, `local/ux-0.18-comments.png`, `local/ux-0.18-documents.png`. 실제 사용자 프로필과 토큰은 저장소에 넣지 않는다.
