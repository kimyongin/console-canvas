# 0.19.0 탐색 UX 개선

2026-10-25. 별도 가상 문서를 직접 사용해 발견한 탐색 마찰 세 가지를 개선했다. **소스·브라우저 직접 사용·배포 빌드 검증과 사용자 설치 앱 갱신을 구별한다.** 설치 앱/스킬은 잠금 때문에 정상 저장·종료를 확인할 수 없어 0.16.1을 유지한다. 실제 사용자 문서는 QA 편집하지 않았다.

## 발견과 개선

| 티켓 | 사용 중 발견 | 구현과 확인 |
| --- | --- | --- |
| [#23](https://github.com/kimyongin/console-canvas/issues/23) 스냅샷 탐색 | 그래프/미리보기를 스크롤하면 제목·현재 기준이 가려지고 멀리 있는 버전을 찾아 돌아오기 어렵다. | 고정 헤더에 이름 검색·부모 이름·현재 버전 찾기. 검색은 휴지통을 제외한 최근 40개 결과와 전체 개수 표시. 선택은 그래프/미리보기만 바꾸고 편집 복원과 구별. 입력 아래 키·결과 방향키/Home/End, 입력 Esc 제공. 검색 결과/현재 찾기·재열기에서 그래프가 보이는 상단으로 복귀. 실제 검색·과거 미리보기·현재 노드 복귀·고정 헤더 사용 확인. |
| [#24](https://github.com/kimyongin/console-canvas/issues/24) 비교 대상 식별 | 변경 위치로 이동해도 어떤 대상인지 눈에 바로 들어오지 않는다. | 양쪽 대상의 같은 번호/이름 테두리와 이전/다음 변경. 삭제/버전 부재는 점선 참고 위치, 좌표는 위치 표시. 처음/마지막·차이 없음의 유효하지 않은 이동은 비활성화. 동기 스크롤에서는 양쪽 대상을 함께 볼 공통 위치로 이동. 실제 100% 확대·다음/이전·번호 테두리 확인. |
| [#25](https://github.com/kimyongin/console-canvas/issues/25) 요청 바로 이동 | 여러 요청 중 멀리 있는 요청으로 이동하려면 이전/다음을 반복해야 한다. | 번호/이름 선택 목록. 이동 전 초안 커밋·열린 검토 순서 유지·비운 주석 재선택·전달 화면 복귀. 자동 저장 때 캔버스 선택이 다른 주석의 제목/저장 상태를 덮어쓰지 않게 분리. 실제 두 요청 직접 선택/자동 저장/전달 복귀, 자동 검사에서 10번째 직접 이동·초안 왕복·다른 캔버스 선택에서 자동 저장 확인. |

## 보존·에이전트

- 저장 스키마·캡처 HTML·원본 locator·편집·주석·분기/휴지통·추가 설명을 바꾸는 이전은 없다. 새 탐색 상태는 영구 편집 이력/실행 취소에 추가하지 않는다.
- React 셸·기존 명령 어댑터에 현재 버전 찾기·비교 이전/다음을 연결했다. 비활성 표시와 명령 실행 경계를 함께 검사한다. 캡처 iframe은 원본 이벤트/스크립트를 실행하지 않는다.
- MCP 13개 도구와 revision/operation_id·dirty/persisted 계약은 유지한다. PRD FR-05/08/15, AC-24~26과 README·스킬/가이드·런타임 ZIP·앱 스킬 ZIP을 갱신했다.

## 검증과 배포 경계

- 타입·포맷·빌드, Python **39개**, Node **27개**, 실제 Chromium **321개** 통과. 기존 302개와 새 navigation 19개다. 최종 앱 런타임을 지정한 Chromium 검사도 같은 321개가 통과했다.
- 새 검사는 A→B→C/A→D의 부모 관계와 조회 전후 편집/활성 버전/revision/undo 불변, 검색 빈 상태/키 이동/고정 헤더/재열기, 비교 삭제/동일 버전/배율, 10요청 초안·자동 저장 대상 문맥을 포함한다.
- 최종 앱의 공식 MCP SDK **22개**, 네이티브 PNG 출력, 격리 스킬 설치/ZIP·정상 종료/재실행과 주석·스냅샷/휴지통·문서명·패널 보존을 offscreen 조건에서 검증했다. 실제 DOM과 가상 캡처 이미지 조건이며 일반 설치 앱의 직접 사용으로 표시하지 않는다.
- 표준 `npm run check`의 마지막 네이티브 수집은 `Current display surface not available for capture`로 실패한다. CUA도 설치 앱 접근 시 Mac 잠금을 보고했다. 브라우저의 직접 사용과 offscreen 성공으로 이 실패를 숨기지 않는다.
- 공식 Electron SHA-256 확인 후 0.19.0 앱·ZIP·DMG를 생성하고 서명/DMG 검사를 통과했다. [AGENTS.md](../AGENTS.md)의 “설치 앱을 교체하기 전 주석 초안·추가 설명까지 저장하고 복구 가능한 백업을 확보한다” 및 “종료·업데이트는 `desktop/lifecycle.cjs`의 같은 저장 응답을 기다린다” 기준에 따라 사용자 앱은 강제 종료/교체하지 않았다. 설치 앱 갱신·재실행·설치 스킬 동기화는 잔여이며 티켓을 열어 둔다.
