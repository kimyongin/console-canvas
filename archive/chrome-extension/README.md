# Chrome 확장 지원 종료

2026-10-29 사용자 결정에 따라 0.25.0부터 내장 Chromium 앱만 공식 지원한다. 이 폴더는 참고용 보관 코드이며 빌드·릴리스·지원 경로가 아니다. 마지막 동작 가능한 전체 구성은 Git 태그 `v0.24.3`에서 확인한다. 보관 실험의 상대 경로는 과거 저장소 구성을 기준으로 하므로 현재 트리에서 실행하지 않는다.

기존 확장과 저장 자료를 자동 삭제하지 않는다. 기존 확장에서 **문서 메뉴 → 편집 파일 저장**으로 각 문서를 내보내고 내장 앱의 **편집 파일 열기**로 가져온다. 주석·스냅샷·분기·휴지통은 파일에 포함된다. 확장과 앱의 저장소는 별개이며 자동 동기화하지 않는다. 모든 필요한 문서를 옮기기 전에 기존 확장을 제거하지 않는다.

내장 앱 수집의 잔여 품질은 #73/#68, 지원 종료 전 확장 시험 기록은 docs/diverse-pages-0.24.3.md와 #69를 따른다.
