# board · Console Canvas 실사용 샘플

독립 실행: 이 디렉터리에서 `python3 -m http.server 59032 --bind 127.0.0.1`.
URL: http://127.0.0.1:59032/
샘플 식별자: ux-study-board
이 실행에서 사용한 캔버스 프로젝트 ID: http://127.0.0.1:59032

외부 의존성·로그인·실제 사용자 자료 없는 가상 데이터 프로젝트입니다. index.html·style.css·app.js가 실제 구현 대상입니다. Canvas는 복제본만 편집하고 소스는 에이전트가 별도로 수정합니다. 폼 저장 결과는 화면 내 테스트 상태이며 외부 서버로 전송하지 않습니다.
