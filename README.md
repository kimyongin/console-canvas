# Console Canvas · 화면 복제 편집기

현재 보고 있는 콘솔 웹 화면을 **소스코드 없이** 가져와 독립된 편집 공간에서 수정하거나 요소별 주석으로 변경 방향을 남기는 로컬 프로토타입입니다. 주 사용 경로는 Chromium을 내장한 독립 앱이며 Chrome 확장은 보조 방식으로 유지합니다. 원본 사이트와 복제본 편집기는 분리되고, AI API 키 없이 로컬 MCP로 에이전트와 연결할 수 있습니다.

캔버스 빈 곳을 드래그해 영역 안의 요소를 한 번에 선택할 수 있습니다. ⌘/Ctrl을 누르면 기존 선택에 추가하고 Esc로 취소합니다. 선택 요소는 복사·붙여넣기 버튼 또는 ⌘/Ctrl+C / V로 같은 화면에 복제합니다. 하위 요소와 주석도 함께 복사되며 실행 취소·스냅샷·파일 내보내기 및 MCP 편집을 지원합니다.

## 독립 앱으로 사용하기

[공개 Releases](https://github.com/kimyongin/console-canvas/releases)에서 `console-canvas-desktop-macos-arm64.dmg`를 내려받아 엽니다. **Console Canvas.app을 Applications로 드래그**하고 DMG를 꺼낸 뒤 응용 프로그램 폴더에서 앱을 실행합니다. GitHub 로그인이나 토큰은 필요하지 않습니다. ZIP도 보조 배포합니다. 현재 macOS Apple Silicon 대상이며 Python 3.9 이상이 필요합니다. 개발용 ad-hoc 서명이며 Apple Developer ID 서명·공증은 아직 적용하지 않아 처음 실행할 때 macOS에서 차단될 수 있습니다. 일반 사용자용 배포를 위해서는 배포 서명·공증이 추가로 필요합니다.

앱 상단 **앱 설정 → 앱 업데이트** 또는 앱 메뉴 **업데이트 확인…** → **업데이트 다운로드** → **업데이트하고 다시 시작**으로 이후 버전을 적용합니다. Git 소스를 실행 중인 앱에 덮어쓰지 않고 GitHub Releases의 완성된 앱을 가져옵니다. GitHub SHA-256, 앱 서명 무결성, 번들 ID·버전·아키텍처를 검증하며 적용 실패 시 이전 앱을 복원합니다. 현재 0.x 개발판은 다음 0.x 시험 릴리스도 표시하고, 1.x 이후는 정식 릴리스만 자동 제안합니다. 편집 데이터·스냅샷·로그인 세션은 사용자 데이터 폴더에 유지하고, 다시 시작할 때 편집하던 문서를 엽니다. 앱이 설치된 폴더에 쓰기 권한이 없거나 DMG 안에서 실행하면 드래그 설치를 안내합니다. 앱 업데이트 후 첫 실행 시 이미 설치된 스킬도 자동으로 갱신합니다. `~/.codex/skills`, `~/.agents/skills`와 실행 환경의 `CODEX_HOME/skills`에 있는 Console Canvas 스킬을 확인하며, 기존 파일은 백업하고 개인 추가 파일은 유지합니다. 스킬이 없으면 **에이전트 연결**에서 처음 한 번 설치합니다. 실패하면 앱은 계속 실행되고 해당 화면과 업데이트 탭에 실패 경로를 표시합니다.

1. 앱 주소창에 실제 웹사이트 URL을 입력합니다. 앱의 별도 세션에서 로그인할 수 있습니다.
2. 원하는 화면에서 **이 화면 가져오기**를 누르면 복제본 편집기가 열리고 **에이전트 연결됨**이 표시됩니다.
3. 직접 요소를 옮기거나 주석을 남기고, 연결한 에이전트에게 주석 조회·편집을 요청합니다.
4. 위쪽 **웹사이트 / 편집기**로 원본과 복제본을 오갈 수 있습니다. 주소창은 **웹사이트**에서만 표시하며 편집기에서는 그 높이만큼 캔버스를 넓게 사용합니다. 편집 도구·확대 비율·스냅샷·변경 전달은 캔버스 위 한 줄 도구막대에 모았습니다. 파일 열기는 왼쪽 원본 제목 메뉴에 있습니다. 창이 좁으면 도구막대를 가로로 스크롤할 수 있습니다. 패널이 열려 있을 때는 패널 상단의 아이콘 버튼으로 접고, 닫힌 상태에서는 도구막대 양끝의 **레이어 / 속성** 버튼으로 다시 엽니다. 패널과 캔버스 사이 경계를 드래그하면 너비를 조절할 수 있습니다. 경계에 포커스를 두고 좌우 방향키로도 조절합니다. 접힘 상태와 조절한 너비는 다음 실행에도 유지하며, 스냅샷이나 주석을 열면 필요한 오른쪽 패널을 자동으로 펼칩니다. **스냅샷** 버튼을 누르면 오른쪽에 저장된 버전 목록이 열립니다. **샘플 콘솔**로 가상 데이터만 사용해 체험할 수도 있습니다.

원본 사이트에는 Node.js나 편집기 preload API를 제공하지 않습니다. 기존 Chrome의 로그인 상태는 자동 공유하지 않습니다. SSO·다중 프레임·특수 리소스의 동작은 사이트별로 검증해야 합니다.

## MCP로 직접 편집

앱 상단 **에이전트 연결**에서 다음을 준비할 수 있습니다.

- **Codex 스킬 설치·업데이트**: 앱에 포함된 스킬을 인터넷 없이 설치합니다. 기존 `~/.codex/skills/console-canvas` 설치가 있으면 재사용하고, 새 설치는 `~/.agents/skills/console-canvas`를 사용합니다. `CODEX_HOME`이 지정되면 해당 경로의 `skills`를 사용합니다. 교체 파일은 스킬 폴더 밖 `console-canvas-skill-backups`에 먼저 백업하며 개인 추가 파일은 유지합니다.
- **스킬 ZIP 저장**: 앱과 같은 버전의 전체 스킬을 저장해 다른 에이전트 환경에 설치할 수 있습니다.
- **MCP 등록 명령 복사**: 앱 내 stdio MCP 어댑터와 실제 로컬 상태 경로를 가리키는 명령을 복사합니다. 터미널에서 한 번 실행한 뒤 에이전트의 MCP 연결을 시작합니다. 앱을 다른 위치로 옮기면 명령을 다시 복사합니다.

MCP와 스킬 설치는 별개입니다. MCP를 연결하면 에이전트는 `get_agent_guide`로 앱에 포함된 최신 `SKILL.md`를 직접 읽을 수 있습니다. 이 조회는 화면을 가져오기 전에도 가능하며 파일을 설치하지 않습니다. 스킬 파일 설치는 `$console-canvas` 검색·호출이나 `prepare`/`review` CLI 도구가 필요할 때 사용합니다. MCP 지침은 앱 번들에서 읽고, 실제 캡처의 문구·주석과 구분합니다.

설치한 스킬의 절대 경로로 MCP 서버를 등록합니다. 기본 설치 위치의 예시는 다음과 같습니다.

```sh
codex mcp add console-canvas -- python3 ~/.codex/skills/console-canvas/scripts/console_canvas.py mcp
codex mcp get console-canvas --json
```

등록한 서버를 사용하는 에이전트는 다음 도구를 호출할 수 있습니다. 새 도구가 나타나지 않으면 MCP 연결을 재시작하거나 새 대화에서 확인합니다.

| 도구 | 기능 |
| --- | --- |
| `get_agent_guide` | 앱에 포함된 스킬 지침·버전 조회, 스킬 설치 불필요 |
| `list_screens` | 명시적으로 연결한 편집 화면 목록 |
| `get_screen` | 현재 버전, 변경·실행 기록 개수, 최근 작업 |
| `list_elements` | 문구·원본 식별자·selector로 검색, 위치·삭제 상태 조회 |
| `list_comments` | 요소별 주석과 원본 식별 정보 조회 |
| `apply_edits` | 이동·삭제·주석 수정·주석 삭제를 원자적으로 적용 |
| `undo`, `redo` | 사람과 에이전트가 공유하는 실행 기록 취소·복원 |
| `list_snapshots` | 저장한 스냅샷 목록·현재 버전·미저장 변경 조회 |
| `create_snapshot`, `restore_snapshot` | 스냅샷 저장·복원, 이동 전 작업 자동 보관 |

예: “가져온 고객 관리 화면의 주석을 읽고, 등록 버튼을 왼쪽으로 120px·아래로 50px 이동해 줘.”

쓰기는 최신 `expected_revision`과 고유 `operation_id`를 요구합니다. 여러 작업을 한 호출로 보내면 실행 취소 한 단계로 묶입니다. 버전 충돌이나 미저장 사용자 입력이 있으면 적용하지 않습니다. 같은 작업의 응답을 받지 못했다면 같은 operation_id와 같은 인수로 재시도해 중복 적용을 막습니다.

MCP는 **가져온 복제본만** 제어합니다. 원본 사이트 수집·로그인은 앱에서 수행합니다. 연결 코드는 로컬의 `~/.codex/console-canvas/connection.json`에 사용자 전용 권한으로 저장하고, 앱에서는 자동 전달합니다. 브리지는 `127.0.0.1`에만 바인딩하며 화면 데이터는 메모리에만 중계합니다. 편집기 자체의 자동 저장은 IndexedDB를 사용합니다.

웹 편집기나 Chrome 확장에서 수동 연결하려면 `python3 mcp/server.py --start`로 서버를 시작하고, **MCP 연결**에서 로컬 주소와 connection.json의 token 값을 입력합니다. 연결을 끊으면 해당 편집 화면은 도구에서 사라집니다.

## 바로 체험하기

[Releases](https://github.com/kimyongin/console-canvas/releases)에서 `Console.Canvas.html`을 내려받아 Chrome에서 엽니다. ‘샘플 콘솔로 시작’을 누르면 실제 HTML로 렌더링한 별도 콘솔 페이지에서 수집한 복제본을 편집할 수 있습니다. 이 파일은 서버 없이 열립니다. 실제 웹사이트를 가져오려면 아래 확장 프로그램을 설치하세요.

저장소를 복제했다면 `python3 scripts/build.py`로 `preview.html`과 `dist/`의 배포 파일을 생성합니다.

## 에이전트 스킬

`skills/console-canvas/`에는 편집기 준비와 전달 파일 해석을 위한 독립 설치형 스킬이 있습니다. 런타임 ZIP도 포함하므로 설치 후 GitHub 연결이나 저장소 경로가 없어도 작동합니다. Python 3만 필요합니다.

```sh
git clone https://github.com/kimyongin/console-canvas.git
cd console-canvas
python3 scripts/install_skill.py
```

기본 설치 위치는 `$CODEX_HOME/skills/console-canvas` 또는 `~/.codex/skills/console-canvas`입니다. 이미 같은 이름의 스킬이 있으면 덮어쓰지 않습니다. 업데이트는 기존 설치본을 확인한 후 `python3 scripts/install_skill.py --update`로 수행합니다. 다른 경로는 `--target /absolute/path/to/skills/console-canvas`로 지정합니다. 스킬 목록이 갱신된 대화에서 다음처럼 요청합니다.

> $console-canvas로 실제 콘솔 화면을 편집할 수 있게 준비해 줘.

편집 결과를 첨부했다면:

> $console-canvas로 첨부한 ZIP을 읽고 이 프로젝트의 UI에 반영해 줘.

에이전트는 비교 이미지와 원본 요소 식별 정보, 부모·자식 이동 관계를 읽고 실제 소스의 레이아웃으로 구현합니다. 소스가 없으면 재구현안이나 수정 명세를 만들 수 있습니다. 실제 사이트 가져오기는 Chrome 확장 버튼으로 시작하며 대화 첨부는 사용자가 합니다.

스킬만 배포하려면 Release의 `console-canvas-skill.zip`을 내려받아 압축 내부의 `console-canvas` 폴더를 스킬 디렉터리에 둡니다. 상세 동작은 [SKILL.md](skills/console-canvas/SKILL.md)에 있습니다.

## 실제 사이트 가져오기

1. 전달받은 `console-canvas-extension.zip`을 압축 해제합니다.
2. Chrome 주소창에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 **console-canvas 폴더**를 선택합니다.
5. 확장 프로그램 목록에서 **Console Canvas**를 고정합니다.
6. 편집할 실제 HTTP·HTTPS 웹사이트를 열고, 필요하면 평소처럼 로그인합니다.
7. 현재 화면에서 **Console Canvas 확장 프로그램 버튼**을 누릅니다. 화면을 읽는 동안 버튼에 ‘…’가 표시되고, 완료되면 독립된 편집기 탭이 열립니다.

원래 사이트의 DOM은 수정하지 않습니다. 원본 스크립트와 이벤트는 복제본에서 실행되지 않습니다. 확장 프로그램은 사용자가 버튼을 누른 탭에 `activeTab`으로 접근합니다. 브라우저 설정·확장 스토어 등 제한 페이지에서는 작동하지 않습니다.

## 편집

- **주석 모드**를 켜면 화면을 움직이지 않고 요소를 클릭해 선택할 수 있습니다. 오른쪽 **이 요소에 주석 남기기**에 “문구를 고객 추가로 바꾸고 오른쪽 위에 배치해 주세요”처럼 자유롭게 적고 **주석 저장**을 누릅니다. 입력창을 벗어나거나 다른 요소를 선택해도 저장됩니다.
- 주석만 작성해 전달할 수도 있고 이동·삭제와 함께 남길 수도 있습니다. 주석은 화면에 자동 적용되지 않습니다. 레이어 목록의 **주석** 표시와 변경 기록에서 해당 요소를 다시 찾을 수 있습니다. **주석 삭제**, 실행 취소·다시 실행도 지원합니다.
- 주석이 달린 요소에는 **보라색 번호 배지**가 표시됩니다. 배지 위에 마우스를 올리면 주석 내용을 미리 볼 수 있고, 클릭하면 오른쪽 입력창에서 바로 수정할 수 있습니다. 레이어·변경 기록에도 같은 번호가 표시됩니다. 배지는 확대·축소 중에도 읽을 수 있는 크기를 유지하고 요소 이동을 따라갑니다. 삭제된 대상의 배지는 점선으로 표시하며, 이 편집용 배지는 내보내는 화면 HTML·PNG에는 포함되지 않습니다.
- 화면의 문구·아이콘·버튼·입력창·체크박스·표 셀·행·영역을 클릭해서 선택합니다.
- 드래그하면 원래 레이아웃 제약에서 벗어나 독립된 레이어로 이동합니다.
- **Shift+클릭**, **상위 요소**, 왼쪽 레이어 트리로 묶음을 선택할 수 있습니다.
- Delete / Backspace 또는 **삭제** 버튼으로 선택한 요소를 숨깁니다. 빈자리는 유지하는 자유 배치 방식입니다.
- 방향키는 1px, Shift+방향키는 10px 이동합니다. 오른쪽 좌표 입력으로도 위치를 정할 수 있습니다.
- Cmd/Ctrl+Z는 실행 취소, Cmd/Ctrl+Shift+Z는 다시 실행입니다.
- 부모 묶음을 이동하면 이미 따로 이동한 자식 요소도 따라갑니다. 부모를 삭제하면 해당 자식도 숨겨집니다.
- 확대 비율과 **너비 맞춤**을 사용하고, 작업 공간을 스크롤해서 긴 페이지를 확인합니다.
- 편집 결과는 해당 브라우저의 IndexedDB에 자동 저장됩니다. 확장을 제거하면 저장 데이터도 없어질 수 있으므로 편집 파일을 따로 저장할 수 있습니다.

## 스냅샷으로 버전 오가기

상단 **스냅샷**을 열고 이름을 적어 **저장**합니다. 이동·삭제·요소별 주석·추가 설명을 한 버전으로 저장합니다. 목록의 버전 또는 **이전 / 다음**을 누르면 그 상태로 돌아갑니다. **가져온 상태**도 시작점으로 남습니다.

과거로 돌아가도 이후 버전은 지워지지 않습니다. 과거에서 새 시안을 저장하면 기존 시안들과 함께 목록에 추가됩니다. 저장하지 않은 작업이 있으면 이동 직전에 **이동 전 작업** 자동 스냅샷으로 보관합니다. 스냅샷 복원 자체도 실행 취소·다시 실행할 수 있습니다. 화면당 최대 500개이며 자동으로 오래된 버전을 지우지 않습니다.

스냅샷은 원본 화면 HTML을 매번 복사하지 않고 편집 데이터만 저장합니다. 화면별 IndexedDB 자동 저장, `.uiclone.json` 편집 파일, 전달 ZIP의 `review.json`에 목록과 현재 버전을 함께 보존합니다. 파일을 다시 열어도 과거·미래 버전을 오갈 수 있습니다. 목록에는 저장 시각, 변경·주석 개수, 현재 버전이 표시됩니다.

## 데이터 저장 위치

독립 앱의 편집 데이터는 macOS의 `~/Library/Application Support/Console Canvas/Partitions/console-canvas-editor/IndexedDB`에 저장됩니다. 브라우저판·확장판은 각각의 출처에 속한 IndexedDB에 저장합니다. 서버나 GitHub로 화면·편집 기록을 자동 업로드하지 않습니다. MCP 연결 정보가 있는 `~/.codex/console-canvas`는 편집 데이터 저장소와 별개입니다.

앱 업데이트는 사용자 데이터 폴더를 유지합니다. 앱 데이터 초기화나 폴더 삭제는 편집 내용을 없애므로 백업·다른 기기로 이동할 때는 **편집 파일 저장** 또는 **전달용 ZIP 다운로드**를 사용합니다. 현재 편집 내용뿐 아니라 과거 스냅샷의 문구·주석도 파일에 포함됩니다.

## 변경 내용을 Codex에 전달하기

1. **변경 내용 전달**을 누릅니다.
2. 필요한 경우 짧은 설명을 추가합니다.
3. **전달용 ZIP 다운로드**를 누릅니다.
4. ZIP 파일을 이 대화에 첨부하고 **“이 편집 결과를 기준으로 수정해 줘”**라고 요청합니다.

ZIP에는 다음 파일이 들어갑니다.

| 파일 | 내용 |
| --- | --- |
| `changes.json` | 요소 식별 정보, 원래 위치, 이동 거리, 최종 위치, 삭제 여부, 요소별 자유 텍스트 주석 |
| `instructions.txt` | Codex에 전달할 편집 방향 |
| `review.html` | 브라우저에서 전후 화면을 전환하며 비교 |
| `before.html`, `after.html` | 원본 복제본과 편집본 |
| `before.png`, `after.png` | 비교 이미지. 생성 가능한 경우 포함 |
| `source-viewport.png` | 가져올 때 실제 Chrome 탭의 화면. 캡처 가능한 경우 포함 |
| `review.json` | 복제본·현재 편집 상태·스냅샷 목록을 보존한 재편집 파일 |

**편집 파일 저장**은 ZIP 대신 `.uiclone.json` 하나를 저장합니다. **화면 파일 열기** 또는 파일 드래그로 다시 열 수 있습니다. 내보내기는 원래 화면의 보이는 문구·이미지·입력값을 포함하며, 비밀번호 입력값은 복제하지 않습니다. 대화로의 전송은 사용자가 파일을 첨부할 때 이루어집니다.

주석은 대상 요소의 ID·원본 selector·문구·좌표에 연결되어 ZIP의 지시문과 비교 화면에도 포함됩니다. 대상이나 상위 영역을 삭제해도 주석은 보존하며 삭제된 대상임을 표시합니다. 이전 버전의 주석 없는 편집 파일도 열 수 있습니다.

## 현재 범위

- 단일 페이지에서 현재 DOM에 렌더링된 일반적인 콘솔 UI가 대상입니다. 다른 경로, 닫힌 화면, 서버에만 있는 데이터, 가상 목록의 아직 렌더링되지 않은 행은 가져오지 않습니다.
- HTML/CSS 기반 복제본을 자유 배치 공간에 표시합니다. 전체 웹페이지를 그래픽 객체로 다시 그리는 렌더러는 아닙니다.
- SVG 아이콘은 한 개의 아이콘 레이어로 다룹니다. Canvas·영상·iframe은 한 개의 이미지/대체 레이어이며, 내부 개체까지 자동 분해하지 않습니다.
- 읽을 수 있는 이미지와 웹폰트는 내장합니다. 외부 도메인·인증 리소스가 읽히지 않으면 원래 주소를 참조하며, 가져오기 참고사항에 표시됩니다. 오프라인 재현은 사이트별로 달라질 수 있습니다.
- 복잡한 변형·Shadow DOM·고정 위치·특수 CSS는 원본과 일부 달라질 수 있습니다. PNG는 보조 이미지이며 HTML 비교본을 함께 확인할 수 있습니다.
- 표의 열 전체 재정렬, 여러 요소 동시 선택, 자동 반응형 레이아웃 생성은 이번 프로토타입 범위에 포함되지 않습니다. 개별 셀·행·내부 요소의 자유 이동과 삭제를 지원합니다.
- 실제 서비스 코드 변경이나 원본 사이트 저장은 수행하지 않습니다. 소스가 있으면 Codex가 편집 기록을 근거로 코드를 수정하고, 소스가 없으면 재구현 방향을 정리할 수 있습니다.

## 개발 및 검증

실행 중인 편집기와 MCP 서버에는 외부 런타임 패키지가 필요 없습니다. 소스 개발·빌드는 Node.js 22.12 이상과 Python 3.9 이상을 사용하며, 개발 의존성으로 Electron·MCP SDK·esbuild·Prettier를 설치합니다.

```sh
npm ci
npm run check
```

`check`는 포맷 검사 → 모듈 번들·스킬 패키징 → Python → Node → 실제 Chromium UI → 독립 앱·공식 MCP SDK·종료 후 재실행 검증을 순서대로 실행합니다. 가상 NORTH 데이터와 임시 프로필·임시 포트만 사용합니다. `npm run format`은 포맷을 정리하고 `npm run test:desktop`은 독립 앱 검증만 실행합니다. 별도로 준비한 Electron은 `ELECTRON_BINARY=/absolute/path/to/Electron npm run check`로 지정할 수 있습니다.

```sh
python3 -m http.server 8848 --bind 127.0.0.1 --directory /absolute/path/to/console-canvas
```

- `http://127.0.0.1:8848/editor.html?sample=1`: 편집기
- `http://127.0.0.1:8848/tests/integration.html`: 실제 DOM 수집·편집·내보내기 통합 검사
- `http://127.0.0.1:8848/tests/panels.html`: 좌우 패널 접기·캔버스 확장·주석 보존·상태 복원 검사
- `http://127.0.0.1:8848/tests/storage.html`: 캡처·편집 분리, 최근 목록, 문서 전환 전 저장 검사
- `http://127.0.0.1:8848/tests/snapshots.html`: 스냅샷 UI·IndexedDB 재실행·파일 재가져오기 검사
- `python3 scripts/build.py`: 포함된 샘플로 독립 실행 데모와 확장 ZIP 생성
- `python3 scripts/build.py --output /absolute/path/to/output`: 배포 출력 위치 지정
- `python3 -m unittest discover -s tests -p 'test_*.py'`: 스킬의 부모·자식 변경 해석, ZIP 처리, 독립 설치·준비 검사

빌드 결과는 `dist/Console Canvas.html`, `dist/console-canvas-extension.zip`, `dist/console-canvas-skill.zip`입니다. 스킬 런타임 자산도 같은 빌드에서 갱신합니다. 저장소에 포함된 `sample.uiclone.json`은 가상 데이터만 사용합니다. 실제 캡처 파일과 사용자 전달 ZIP은 커밋하지 않습니다.

브라우저 검사 121개와 독립 HTML 파일 실행, Python 37개, Node 16개, 공식 MCP SDK 실제 연결 18개를 통과했습니다. 358개 표시 요소의 이동·삭제·복원, 문서 전환 전 저장, 앱 종료·재실행 후 복원을 확인했습니다. 상세 검증 범위는 [docs/verification.md](docs/verification.md)에 있습니다. **개인 Chrome에 확장을 설치한 뒤 탭 권한으로 실제 사이트를 가져오는 경계는 아직 검증하지 않았습니다.**

Chrome 확장의 권한은 `activeTab`, `scripting`, `storage`, `unlimitedStorage`와 로컬 MCP 연결용 `http://127.0.0.1/*` 접근입니다. 원격 서버나 AI API에 데이터를 전송하는 기능은 없습니다.

구조와 저장·종료 흐름은 [docs/architecture.md](docs/architecture.md)에 정리했습니다. `editor.js`는 모듈을 연결하고, `ui/`는 화면별 표시, `editor-session.js`는 편집 기록·저장, `edit-commands.js`는 수동 편집과 MCP의 공통 명령을 담당합니다.

0.8 개발판은 새 IndexedDB `console-canvas-workspace`를 사용합니다. 기존 0.7 저장소의 자동 이관·호환 계층은 포함하지 않습니다. 필요한 기존 화면은 이전 앱에서 편집 파일로 저장한 뒤 새 앱에서 가져올 수 있습니다.

### 독립 앱 빌드·검증

```sh
python3 scripts/build_desktop.py
python3 scripts/install_desktop.py
```

공식 Electron 릴리스의 SHA-256을 확인한 뒤 `dist/Console Canvas.app`과 `dist/console-canvas-desktop-macos-arm64.zip`을 생성합니다. `--download-only`는 런타임 준비만 수행합니다. 설치 위치는 기본 `~/Applications/Console Canvas.app`이며 기존 앱은 `--update`를 지정한 Console Canvas만 교체합니다.

Node.js 개발 환경에서는 `npm install` 후 `npm start`로 소스를 실행할 수 있습니다. Python 실행 파일은 `CONSOLE_CANVAS_PYTHON`, 로컬 상태 폴더는 `CONSOLE_CANVAS_STATE_DIR`, 개발용 브리지 포트는 `CONSOLE_CANVAS_PORT`(기본 8849)로 지정할 수 있습니다. 일반 CLI 서버의 상태 폴더는 `--state-dir`로 지정합니다.

독립 앱에서 가상 **샘플 콘솔**을 가져온 뒤 `node scripts/verify_mcp.mjs`를 실행하면 공식 SDK가 실제 stdio MCP 서버와 통신해 이동·삭제·주석 수정·실행 취소·재전송·버전 충돌을 검증합니다. 사용자 실제 데이터에는 이 검증 스크립트를 사용하지 않습니다.

### 0.9 편집 흐름

원본 제목을 누르면 주소·캡처 크기·파일 열기·원본에서 다시 가져오기가 펼쳐집니다. 편집 도구와 확대는 가운데, 스냅샷과 변경 전달은 도구막대 오른쪽에 고정합니다. 에이전트 연결·앱 업데이트는 외부 셸의 **설정** 메뉴에서 엽니다.

레이어 이름과 상위 경로를 읽기 쉽게 표시하며 **주요 요소만**으로 목록을 줄일 수 있습니다. 모든 요소는 전체 목록과 **Alt+클릭**으로 계속 선택합니다. **Cmd/Ctrl+클릭**으로 여러 요소를 선택해 함께 이동·삭제하고, 오른쪽에서 정렬·간격 맞춤·선택적 스냅을 사용합니다. 부모와 자식을 함께 선택해도 이동은 중복 적용되지 않습니다.

**주석 모드**에서는 요소 옆에서 바로 작성하고 자동 저장합니다. Cmd/Ctrl+Enter로 저장 후 닫으며, 오른쪽 **주석** 탭에서 검색·대상 이동·수정을 합니다. **스냅샷**은 배치 미리보기와 원본·현재·두 저장 버전 비교를 제공합니다. 미리보기는 외부 리소스가 일부 빠질 수 있으며, 비교는 현재 작업을 복원하거나 변경하지 않습니다. **변경 내용 전달**에서는 전달 기준 버전을 선택하고 이동·삭제·주석을 검토합니다. 편집 파일과 ZIP에는 전체 스냅샷 목록을 포함합니다.

0.11부터 도구막대의 **문서**로 저장된 화면을 검색하고 전환합니다. 전환 전 주석 초안과 추가 설명을 저장합니다. 다중 선택은 공통 점선 외곽선 위 **N개 이동** 손잡이로 함께 이동하며 한 번에 실행 취소합니다. 오른쪽 위 **앱 설정**은 에이전트 연결·스킬 설치·업데이트를 관리하는 별도 화면입니다.
